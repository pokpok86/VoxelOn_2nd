# 무기·파츠 옵션 사용법

게임을 실행하고 기체 선택 화면의 **WEAPON / PART OPTIONS**를 누릅니다.

1. **무기**: 목록에서 장비를 선택하고 이름·특성 표기·메모·성능 수치를 입력합니다.
2. **파츠**: 현재 선택 가능한 WISP·BASTION·TARANTULA의 머리, 코어, 좌우 팔, 하체, 부스터를 편집합니다.
3. **좌우 장착**: 왼손·오른손·왼쪽 어깨·오른쪽 어깨를 독립적으로 고릅니다. 같은 총도 양손에 각각 장착할 수 있습니다. 무기 탭의 손/어깨·왼쪽/오른쪽 허용 설정을 따릅니다.
4. **파일 저장**을 누르면 즉시 JSON 파일에 기록됩니다. 이전 파일은 `.json.bak`으로 남습니다.
5. **전투에 적용**을 누르면 플레이어와 AI에 동일한 설정이 적용됩니다. 저장과 적용은 별도입니다.
6. 저장 파일을 다시 쓰려면 **파일 불러오기 → 전투에 적용**을 누릅니다. 재실행 시에도 파일을 불러와 적용할 수 있습니다.

이 PC의 기본 파일:

`D:\Codex\VoxSky\Builds\WorkLatest\Data\Balance\PD-Balance.json`

파일 탭에서 다른 이름으로 저장하여 여러 밸런스안을 보관할 수 있습니다. 프로그램을 별도 PC로 옮기면 화면 하단에 표시되는 실제 저장 경로를 사용합니다. 원본 설정은 [템플릿](PD-Balance-Template.json)에 있으며, 게임 내 저장은 이 문서용 템플릿을 수정하지 않습니다.

## 장비와 조작

- 슬롯1은 왼손, 슬롯2는 오른손, 슬롯3·4는 좌우 어깨입니다. 1~4로 선택한 뒤 왼쪽 클릭으로 사용합니다.
- 총을 오른손에 장착하면 기존 실물 방패는 내려놓습니다. **기본 방패(WISP 오른손)**를 선택하면 총 대신 방패와 기존 우클릭 가드 자세를 사용합니다.
- **미장착**을 손 슬롯에 고르면 해당 손을 선택했을 때 주먹 공격을 합니다. 빈 어깨 슬롯은 장착물이 없습니다.
- 어깨 무장은 실제 어깨 관절의 자식입니다. 팔을 들거나 돌리면 함께 움직이고, 선택한 어깨 무장의 발사 자세는 요청한 조준 방향에 맞춥니다.
- 기본 실물 방패는 기존 가드 자세·이동 페널티를 사용합니다. 기존 기체 에너지 실드 규칙은 유지합니다.

## 지금 적용되는 수치

총기: 탄창, 공격력, 발사 간격, 탄속, 탄환 판정 반경, 사거리, 잔탄/빈 탄창 장전 시간, 자동 장전 대기, 추가 탄퍼짐, 기존 폭발 반경.

파츠: 내구도·장갑·에너지 용량, 센서/레이더, 좌우 팔 조작성·안정성, 이동/방향 비율, 점프/낙하, 부스터 수치. `기본 속도`와 `전용 이동 기준속도`는 해당 기체가 사용하는 이동 방식에 따라 적용됩니다.

**주황색 [보관] 항목**은 파일에 저장되지만 현재 전투에 반영되지 않습니다. 무기/탄약/파츠 무게, 반동, 무기별 락온·페널티, 에너지 무기 소모·과열·냉각은 후속 특성을 정하기 위한 기록입니다. 파일의 표시 상태만 바꿔도 새 전투 규칙이 생기지는 않습니다.

32종의 신규 Blender 외형에 기존 기본 방패와 미장착을 더해 편집 목록은 **34개**입니다. 현재 장착·공격을 지원하는 것은 총기15종, 기존 WISP 방패, 미장착 손의 주먹입니다. 검·해머·추가 실드·드론·투척물·옵션 모듈은 외형/수치 보관 단계입니다. 산탄·빔·화염 등의 이름은 외형 분류이며, 전용 공격 방식은 별도로 정할 항목입니다.

새 무기 외형 전체는 기체 선택 화면 **WEAPON GALLERY / F3**에서 볼 수 있습니다. 갤러리의 슬롯 표시는 현재 선택 기체에 실제 적용된 장착 상태입니다. 같은 무기를 양손에 적용하면 두 슬롯을 함께 표시합니다. 아직 적용하지 않은 편집 초안과 구분됩니다.

## 파일을 직접 편집할 때

`formatVersion: 1`과 ID·항목 키·목록 구조를 유지하고 `value`, 이름·메모·장착 허용·기체별 `slots`를 편집합니다. 허용 범위를 벗어난 값, NaN/무한대, 소수 탄창, 알 수 없는 ID, 장착 조건 위반은 저장/적용이 거부됩니다. 오류가 나도 기존 파일을 덮어쓰지 않습니다.
