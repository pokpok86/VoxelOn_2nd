직접 확인: 머리/몸체가 박스처럼 보이던 인상이 줄고, 참고 사진의 흰 차체·주황 어깨·검은 관절·작은 눈 조합에 가까워졌다. 참고보다 옆/뒷면 설비가 단순하고 발목은 직선 피스톤 느낌이 강하다. 최종 디자인 승인 전이다. 스튜디오 조명은 재질 흰색을 푸르게 보이게 하므로 Blender 렌더/실제 게임 화면도 함께 본다.

기존 15장 고정 배율은 비교를 위해 유지한다. 사족은 다리 끝이 잘리므로 별도5장 -wide 전신 구도를 추가한다. 넓은 구도를 이전 고정 배율 그림과 픽셀 크기 변화로 비교하지 않는다.

검증:
- Blender 닫힌 메시·양의 부피 검사, 얇은 앞치마 모서리 교차 방지. 새 FBX WISP_v009 / BASTION_v004 / TARANTULA_v004.
- `Logs/Nacchin-Iteration03-Build.log`: Windows 성공204310562 bytes. 회귀335개 통과(관절·방패·접지·실제 스킨 메시 움직임 포함).
- Canyon 세 기체 각15초 실제 이동·점프·네 슬롯 사격·AI 추적21개 통과. AI 이동거리205.91/218.64/214.67m, 최장 정지0/.74/0초. 이 열린 구간 결과를 모든 엄폐물 경로 보장으로 확대하지 않는다.
- 같은 테스트 렌더 평균6.99~7.00ms / p95 7.07~7.08ms. 현 PC/개발빌드/특정 장면 결과.
- UI 없는 실제 연기 근접 촬영으로 장갑 앞쪽에 생성된 작은 짙은 연기를 확인했다. 일반 후방 시점 가독성은 추가 개선 대상이며 단순 활성 검사와 구분한다.
FullFrame 촬영 보완 빌드204310606bytes 성공. 실제20장 생성, 사족 전신 사선도 직접 확인했다. 이어 실내 세 기체 각15초 동작21개 통과: AI이동194.17/209.56/213.15m, 최장정지0/.74/0초. 실내·실외 총42개 동작검사는 이번 두 장면에 대한 결과이며 모서리 고립 상황 전수검사나 수동 플레이 승인이 아니다. 7ms 측정은 프레임 제한/동기화가 있는 현재 설정의 실제 간격으로, GPU/CPU 순수 렌더 비용을 뜻하지 않는다.
