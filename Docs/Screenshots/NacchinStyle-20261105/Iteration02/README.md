02 Blender 렌더를 직접 확인했다. 손 노출 및 경사는 개선됐다. 참고 사진보다 머리와 앞치마가 단순한 상자 형태로 남아 있으며 최종 비주얼 승인 대기다. Unity에서 흰색이 푸르게 보이는 조명 차이도 추가 비교 대상이다.

02 최초 빌드는 성공했으나 모델 버전명 화이트리스트에서 v008이 빠져 리그/접지/방패 검사들이 실패했다. 검사 조건을 낮추지 않고 실제 리그 경로로 판별하도록 수정했다. 수정 후 빌드 성공. 회귀334개 통과, Unity 동일각도15장 확인. 전투 동작 테스트는 WISP 고정 전방 조준에 적 추적 벡터를 넣어 사격각 밖에서 시험하던 오류를 수정했다. 실제 생성 발사체와 네 슬롯 각각 발사를 요구하도록 강화해18개 통과. 프레임 평균6.99~7.00ms, p95 7.06~7.08ms(본 PC/개발빌드/실내 15초씩, 일반 성능 보장 아님). 외곽 벽이 있고 독립 장애물이 제거된 Canyon 날씨25개 통과,8장 생성. 효과5장/상태 검사는 통과했지만 실제 그림에서 팔 연기가 보이지 않고 공중 분사는 작아 시각 검증 미완료다. 다음 반복에서 연기 발생 시각과 카메라 가독성 수정 필요.
