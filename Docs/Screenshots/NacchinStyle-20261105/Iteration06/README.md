# 궤도 반복06 — 직선 접지·전륜·실제 구동

Blender 새 BASTION_v006.blend/FBX/프리팹, 176메시/4600정점/115뼈. WISP_v011/TARANTULA_v005와 기존 원본은 그대로 보존했다. 같은 흰색·주황색 소체 비례를 유지하며 하체만 다듬었다.

- 타원형 궤도를 직선 상·하부와 둥근 끝단이 있는 경로로 변경했다. 끝의 큰 구동/유도륜과 아래쪽 작은 전륜3개를 배치했다.
- 실제 바퀴/허브가 굴러가고, 선회 시 좌우 궤도가 다른 거리만큼 움직인다. 전투 속도/조향 규칙을 바꾼 것이 아니라 기존 이동을 모델에 반영한다.
- Blender 메타 뼈 `TrackPath_Capsule_v001`이 있는 새 모델에만 적용한다. 구 모델은 기존 경로를 유지한다. 경로 반지름 .38, 직선 반길이 .41, 링크40개씩, 기존 관절 이름 유지.

발견/수정:
- 스폰 때 방향 초기화를 실제 선회로 계산해 좌우 궤도가 어긋나던 상태 오류를 회귀 검사에서 발견, 라운드 초기화에서 주행/회전 위상을 초기화했다.
- 상체 기울기를 상쇄해도 하체 뼈 위치는 위아래로 움직였다. 실제 Blender 하체 밑면으로 고정점을 계산하고 상체 기울기와 하체 위치를 분리했다. 점프 시에는 실제 게임 루트 높이를 따라간다.
