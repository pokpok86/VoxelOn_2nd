# F2 실제 4무장 조정 수정

기존 WEAPONS 페이지는 보관 중인 옛 PRIMARY/SPECIAL 또는 픽업 도구를 조절했으며 실제 4슬롯 프로필을 편집하지 못했다. 이를 고쳤다.

- F2 → PILOT/RIVAL → WEAPONS →1~4: 해당 기체·슬롯의 피해/발사 간격/탄속/판정 반경/사거리를 런타임에서 편집한다. 실제 발사·조준 거리·AI 탄속 예측·HUD가 같은 프로필을 쓴다.
- 각 기체·슬롯은 깊게 복사한 별도 프로필이다. 한쪽 수정이 상대나 원본 기본값을 바꾸지 않는다. RESET THIS WEAPON/RESET THIS FRAME으로 기본값 복원.
- 기본 30/8/12/4 탄창과2.5/4초 장전, 기존 기본 피해·탄속·빈도는 변경하지 않았다. 픽업 도구는 PICKUP TOOLS로 보존했다. 편집값은 디스크/프리셋에 저장하지 않는다.
- 다리 페이지를 열 때 기존 최소값 .05 때문에 방패 장착 페널티 .02가 .05로 조용히 바뀌는 문제도 수정했다. 슬라이더 상한이 현재값을 따라 계속 커지던 문제는 원본 프리셋 기준으로 고정했다.
