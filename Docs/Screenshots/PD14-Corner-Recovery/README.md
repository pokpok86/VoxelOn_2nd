# 실제 AI 모서리 회복 테스트

실행: `Voxel-On.exe --corner-soak --outdoor -logFile <절대경로>`

게임과 같은 EnemyAI/Move/Attack/충돌 함수를 실제 렌더 프레임에서 호출한다. 세 기체 × 경계 구석/높은 L자 엄폐물 × 5검사 =30검사, 각8초다. HP복원·고정 상대 위치는 테스트 조건이다. 시험용 L자 구조물은 이 모드에서만 생성하며 일반 Canyon에는 추가되지 않는다.

발견: 기존 TARANTULA는 L자에서151.75m를 움직여도 순변위3.72m이고 상대를 볼 수 없었다. 속도만으로 판단하는 기존 stuckTime은 이런 선회를 잡지 못했다. [실패 장면](Before/3-case-1.png), 로그 `Logs/Nacchin-Iteration04-corner-soak.log` 보존.

수정: 가까운 장애물의 충돌 반경 밖 모서리를 연결하는 작은 가시성 경로를 계산해 첫 우회 지점을 따른다. 경로가 없으면 기존 행동을 유지하고, 사격 시야가 열리면 원래 궤도 이동으로 돌아간다. 명중률·무기 반응 간격·재장전·난이도 수치는 바꾸지 않았다. 우회가 기존 장애물 점프 감지를 지우는 회귀도 전체 검사에서 발견해 점프 감지 후 방향 적용 순서로 수정했다. 실패 검사를 지우거나 기준을 낮추지 않았다.

최신 `Nacchin-Iteration04-CornerJumpFix` 빌드 성공 / 기존 회귀335개 / 모서리30개 통과.
