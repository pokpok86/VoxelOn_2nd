# WISP 게임 내 관절 확인 및 수정

## 발견하고 수정한 문제

1. 이족형이 좌우 이동할 때 고관절이 앞뒤로만 움직였다. 이동 방향에 따라 고관절의 앞뒤/좌우 회전을 분리하고, 발목이 상위 관절의 기울기를 보정하도록 했다. 4족 고관절도 이동 방향을 반영한다.
2. 기본 자세에서 발과 궤도가 약 3.6~10.2cm 떠 있었다. 발목·4족 발끝·궤도 메시의 실제 지지 정점을 측정해 전체 외형을 함께 이동시킨다. 허리/고관절/팔꿈치 연결을 유지하면서 컨트롤러의 발바닥 높이에 맞춘다. 호버의 의도된 부유 높이는 유지한다.
3. 하박의 위치만 팔꿈치에 맞고, 조준/가드 시 원통 회전축 방향은 상박과 달라질 수 있었다. 어깨 자세를 최소한으로 보정하여 상박과 하박의 원통 축을 일치시키고, 휴대 자세도 상박 회전에서 계산한다. 총구는 조준 방향을 유지한다.

Blender 원본의 형태·치수, PD 성능 수치, 어깨 무장 제거 규칙은 변경하지 않았다.

## 실제 실행 확인

- Unity **6000.6.7f1** Windows 빌드: `VOXSKY_BUILD_PASS 250389802 bytes`.
- 실행 파일에서 `--wisp-joint-review`: **60개 검사 통과**.
- STRIDER/WISP, BASTION TRACK/BASTION, TARANTULAN/TARANTULA, SKYLIFT/WISP 외형 조합에 정지·전진·후진·좌·우 이동·점프 상승·착지·위 조준·아래 조준·방패 가드 적용.
- 실제 `Move`/`Animate` 경로를 0.025초씩 **2,560회** 실행하고 실제 메시 지지 높이를 320회 측정했다. 키보드 수동 플레이를 했다는 뜻은 아니다.
- 팔꿈치 중심 간격 최대 **0.00001m**, 원통 축 방향 오차 최대 **0.020도**. 평지 이동/정지 표본의 최저 지지점 높이는 지면과 측정 정밀도 내 일치했다.
- 이족/4족은 실제 점프 상승 중 보행 정지, 착지 완료를 확인했다. 관절이 없는 호버에는 고관절 정지 검사를 적용하지 않는다.
- 최종 빌드에서 기존 신형 파츠 검사도 재실행하여 **41개 통과**했다. 어깨 모델/포구 부재, 발사 차단, 무기 제거와 별도 외형 설정 저장 등 포함.
- 40개 자세 캡처를 비교 시트로 열어 확인했다. 걷기 GIF는 실제 Unity 렌더 8장을 시간 순서로 연결했으며 새로 그린 애니메이션이 아니다.
- Arena.unity와 PD-Balance.json SHA-256은 작업 전과 동일하다.

## 확인 범위

평지에서의 동작과 관절 중심/회전축/지지점 검사다. 경사·계단의 개별 발 IK, 모든 극단적 조준각의 장갑 접촉, 전체 전투 밸런스를 검증한 것은 아니다. 호버는 기존처럼 외형 적용이며 별도 호버 이동 물리를 새로 추가하지 않았다.
