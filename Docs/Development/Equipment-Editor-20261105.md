## 발견·수정한 실패와 비교

1. 최초 Blender 실행에서 World가 없었습니다. World를 생성하고 `--python-exit-code 2`와 명시적 성공 마커를 함께 사용했습니다.
2. 실내 WISP 레일 총구가 몸체 충돌 범위 밖으로 나가 측면 엄폐물에 걸렸습니다. 실제 장착 위치의 회피와 정상 총구 검증을 추가했습니다. 정면 엄폐물 차단 검사를 그대로 유지했습니다. 실패 로그를 보존했습니다.
3. 높게 올린 어깨 장착은 박PD가 반려했습니다. 머리 위 고정이 아닌 어깨 옆의 관절 연결로 수정했습니다. `Unity-v003-high-mount`는 반려된 이력이며 최종본이 아닙니다.
4. 편집 창 문자열 줄바꿈 컴파일 오류를 수정했습니다.
5. 편집 템플릿에 보관된 HOUND가 포함되어 2개 검사가 실패했습니다. 실제 잠금 해제된 세 기체만 포함하도록 수정했습니다.
6. 어깨 뼈 아래로 옮긴 무장이 기존 몸체 높이 측정에 섞였습니다. 몸체 높이3.5105m ±0.025 기준은 유지하고 무장을 분리 측정했습니다. 무장에 별도 유한 크기 검사를 추가했습니다. 실패 검사를 삭제하거나 기준을 완화하지 않았습니다.
7. 초기 손 근접 사진에서 몸통이 손을 가렸습니다. 최종 비교에서는 실제 스킨/바인드 버텍스 위치로 중심을 계산하고 장갑만 따로 촬영하여 확인했습니다. 초기 사진은 이력으로 남겼습니다.

- 무게·반동·과열·에너지 무기 비용·무기별 락온 페널티는 저장만 합니다. 검·해머·추가 실드·드론·투척물·모듈은 외형/수치 보관 단계입니다. 기본 실물 방패는 기존 가드 모션·이동 페널티와 기체 에너지 실드 규칙을 사용하며, 새로운 방패 내구도/추가 피해 감소 규칙은 구현하지 않았습니다.
