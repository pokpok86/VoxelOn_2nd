# 양손 총기 기본 동작 — 2026-11-18

## PD 지시와 적용 범위

방패는 현재 선택 목록과 정상 전투에서 제외했다. 이전 저장에 남은 알려진 방패 ID는 실제 장착 시 UNARMED로 해석하며 원본 자산·저장 데이터는 보관한다. 호환성용 가드 함수와 과거 검사 fixture는 남아 있지만 정상 선택으로는 방패를 장착할 수 없다. 어깨 무장은 기존 준비 중 상태를 유지한다.

왼손·오른손 화살표는 외형 장식 선택 대신 실제 BalanceDesign 슬롯의 총기를 바꾼다. 선택한 총기의 제작된 모델과 GRIP_MAIN/MUZZLE 연결점을 사용한다. 과거 외형 파일의 무기 덮어쓰기는 실제 장착 총기에 우선하지 않는다. 수치 편집으로 바로 이동할 수 있다. 양손은 1/2로 활성 무기를 선택하고 좌클릭 기본 공격, 우클릭 특수 동작을 사용한다.

FOCUS: 우클릭을 누르고 지상 정지 시 탄퍼짐 35%. BRACE: 지상 우클릭 동안 이동/부스터를 멈추고 탄퍼짐을 줄이며 카메라 반동은 설정치의 30%로 적용한다. 일반 발사 때 생기는 바주카의 1.5 속도 밀림도 없앤다. 공중에서는 고정 포격 보너스가 적용되지 않는다. LOCK_ON: 기존의 무기별 명시적 락온을 사용한다. 유도 지속 수치가 0이면 임의로 유도탄을 만들지 않는다.

기존 우클릭 NONE 총기는 FOCUS, Future_Launcher는 LOCK_ON, 기존 Military_RL의 NONE/LOCK_ON은 BRACE로 해석한다. 우클릭 동작은 편집기에서 선택 가능하며 원래 PD 숫자를 자동으로 재조정하지 않았다. 위 계수와 분사 패턴은 구현 확인용 값이며 최종 밸런스 확정이 아니다.

산탄·분사는 발사 1회 총 공격력을 투사체들에 분배해 공격력이 탄 수만큼 증가하지 않는다. 빔도 설정 공격력을 1회 발사 지속시간으로 분배한다. 화염은 현재 근거리 분사형 투사체 단계이며 연소 상태이상·전용 연속 화염 효과·열/에너지 소비 체계까지 구현한 것은 아니다.
