# 무기·스킬 조합 기체 프리셋 — 2026-11-08

현재 사용 중이던 DESIGN_01~03과 모든 무기 수치·특성·장착 분류는 그대로 두고, 중복 기본값이 있던 DESIGN_04~08에 다섯 가지 역할 프리셋을 채웠다. 기존 기체 파츠 값도 바꾸지 않았다.

이 구성은 새 무기 규칙이나 새 성능 수치를 만들지 않는다. 현재 `PD-Balance.json`에 있는 무기의 이름·수치·손/어깨 허용 값과 구현된 스킬을 조합했다. 따라서 이후 PD가 무기 수치나 분류를 조정하면 설계에도 현재 데이터가 반영된다.

## 확인

- JSON 파싱과 8개 설계 슬롯 수를 확인했다.
- 신규 다섯 설계의 기체·스킬 ID와 무기 ID가 기존 데이터에 존재하는지 확인했다.
- 각 무기가 좌/우 및 손/어깨 슬롯에 현재 허용된 조합인지 검사했다.
- 원본 무기 목록, 파츠 목록, DESIGN_01~03, 그리고 DESIGN_04~08의 파츠 데이터는 수정 전 원본과 동일함을 확인했다.
- 실행 중인 Unity Editor/빌드는 없었다. 이 회차는 밸런스 JSON 데이터만 수정했으며 Unity 빌드는 실행하지 않았다.
