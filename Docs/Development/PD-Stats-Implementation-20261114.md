# PD 무기·파츠 속성 기준 적용 기록 — 2026-11-14

## 범위

PD가 요청한 세 항목을 현재 작업 브랜치에 반영했다. 메인 브랜치, `Data/Balance/PD-Balance.json`, Arena 씬, Blender 원본은 수정하지 않았다.

## 적용 항목

1. **기존 저장 파일 호환성 및 몸통 방어율**
   - 밸런스 문서 형식을 7로 올리고 v1–v6 파일을 계속 읽는다. 구형 락온/방패 아이콘 값은 새 명시 동작 필드(`secondaryActionId`)로 옮겨 기존 의도를 보존한다.
   - 구형 분리 재장전 시간, 방어율 등 내부 수치는 저장 파일에서 제거하지 않는다. 새 편집 화면은 통합 재장전 수치만 기본 항목으로 보여 준다.
   - 현재 선택 가능한 기체에는 기존 몸통 방어율을 전투 피해 감소로 적용하지 않도록 했다. 구형 수치는 파일에 보존된다. 실드의 가드 동작은 무기 종류와 명시 동작이 지정된 경우에만 계속 적용된다.

2. **표시 아이콘과 실제 기능 분리**
   - 특성 아이콘은 표시 용도로만 사용한다. 아이콘만으로 락온이나 실드 기능, 장착 위치가 바뀌지 않는다.
   - 락온은 명시적 우클릭 동작 설정으로 판단한다. 기존 v1–v6 파일의 `LOCK` 및 실드 아이콘은 마이그레이션 단계에서 동작으로 보존한다.
   - 무기·파츠 고유 기능 ID는 별도 필드에 보존·왕복 저장한다. 아직 PD가 정하지 않은 효과나 수치는 실행하지 않는다.

3. **편집 화면 기본 수치 간소화**
   - 무기 기본 편집 항목은 공격력, 발사 간격, 탄속, 판정 반경, 사거리, 탄창 크기, 재장전 시간, 무게, 반동으로 제한했다.
   - 머리: 감지 성능·무게, 몸통: 내구도·에너지 용량·무게, 다리: 이동력·점프력·무게, 백팩: 부스터 성능·무게만 기본 수치로 제공한다. 파츠 무게는 기존 `plannedWeight` 초안 값을 편집·저장하며, 아직 전투 계산에는 반영되지 않는다고 표시한다.
   - 좌·우 팔은 별도 전투 수치 대신 통합 설명을 보인다. 기존 조작/안정성 값 및 나머지 숨은 내부 수치는 저장·내부 호환을 위해 유지한다.
