# WISP 신규 파츠 게임 연결 — 2026-11-12

## 적용 내용

- 승인된 Blender 비율을 유지한 BD01·HD01, 하박 무장 5종, 사진 기준 백팩 5종, 하체 4종을 실제 Unity 메시로 연결했다. 기존 Blender 원본은 수정하지 않았다.
- 커스터마이징의 **신형 외형**에서 백팩·하체·슬롯별 무기 외형을 화살표로 변경한다. 기본 AUTO는 기존 무장 종류에 맞춰 매핑하고, 빈 슬롯과 방패 여부는 실제 장착 상태를 따른다. 기존 외형으로 복귀하는 버튼도 있다.
- WISP·BASTION·TARANTULA에 기본 적용한다. HOUND 및 보관용 다른 콘셉트의 외형은 자동 교체하지 않는다.
- 조준하는 무장은 실제 포구를 향해 회전하며 발사 위치도 새 포구를 사용한다. 방패 가드, 공중 다리 보행 정지, 이족·4족 관절, 바퀴·궤도 동작을 연결했다.
- 외형 선택은 설계/기체별 `Data/Balance/WISP-Visual-Loadouts.json`에 별도로 자동 저장한다. PD-Balance의 수치와 기존 파츠 선택 ID는 변경하지 않았다.

## 범위와 제한

이번 단계는 새 외형과 기존 게임 동작의 연결이다. 외형을 바꿔도 기존 프레임의 이동 방식·충돌 범위·무기 성능·무게·에너지 수치는 그대로다. 예를 들어 WISP에서 SKYLIFT 외형을 선택해도 신규 호버 물리가 생기는 것은 아니다. 하체 물리와 백팩 성능의 개별 연결은 후속 범위다.

무장 AUTO는 기존 종류의 분류를 이용하는 시각적 대응이다. 기존 모든 무기의 개별 고유 모델을 제작한 것은 아니다. 새 파츠의 Blender 렌더와 Unity 조명/재질의 인상은 다를 수 있으며 디자인 승인을 대신하지 않는다.

## 실제 검증

- Unity **6000.6.7f1** Windows Development 빌드 완료: `VOXSKY_BUILD_PASS 250377126 bytes`.
- 최종 실행 파일의 `--wisp-family-review`: **35개 검사 통과**. 실제 메시 버퍼, 4종 하체/백팩 장착, 허리 접속 위치, 무장 선택·제거, 방패 가드 회전, 새 포구, 공중 보행 정지, 별도 설정 저장/읽기를 검사했다. 시험 저장은 임시 폴더에서 수행했다.
- 이전 외형 경로를 명시한 `--smoke-test --legacy-family-art`: **383개 통과**. 기존 전투·카메라·이동·AI 등 보존 경로의 회귀 검사이며, 신형 모드 전체 383개 통과라는 뜻은 아니다.
- 초기 신형 모드 스모크에서는 이전 FBX 이름·계층·고정 치수를 요구하는 검사 등 14개가 실패했다. 다른 콘셉트까지 자동 교체하던 범위를 수정했고, 기존 모델 검사와 신형 전용 검증을 구분했다. 이전 FBX 구조에 의존하는 전체 검사기의 신형 대응은 아직 완료하지 않았다.
- 실제 실행 이미지의 뒤집힌 면과 편집창 오른쪽 잘림을 발견해 수정 후 재빌드·재검사했다. 최종 게임 화면/커스터마이징 및 세로형 파츠 장착 이미지를 직접 열어 확인했다.
- Arena.unity와 PD-Balance.json의 SHA-256은 작업 전과 일치한다. Robot/BalanceEditor 파일에 원래 있던 미커밋 수정도 보존했다. 기존 실행 가능한 Windows 빌드는 임시 백업에 보관했다.

## 후속 요청: 어깨 무장 임시 제거

어깨 무장은 향후 백팩에 설치한다는 PD 지시에 따라, 현재 일반 실행에서는 모든 기체의 3·4번 슬롯을 실행 중 미장착으로 처리한다. 모델·포구를 생성하지 않고 선택/사격도 차단하며 HUD에는 EMPTY를 표시한다. 커스터마이징의 어깨 행은 준비 중으로 고정하고, 신형 외형 탭에는 하박 2개만 선택하도록 했다. 저장된 PD 장비 ID와 수치는 삭제하거나 변경하지 않았다. 이전 모델 전용 회귀 실행 옵션은 기존 경로를 유지한다.

Unity 6000.6.7f1 재빌드 성공(250378458 bytes), 실제 실행 검사 **41개 통과**. 양쪽 어깨 모델/포구 부재, 강제 슬롯 선택 후 발사 차단, 숫자 선택 제외 검사를 포함한다. 새 스크린샷을 열어 어깨 무장 제거와 HUD EMPTY 표시를 확인했다. 씬과 PD-Balance.json은 변경 전 SHA-256과 일치한다. 이 버전에서 이전 외형 383개 검사를 다시 실행하지는 않았다.
