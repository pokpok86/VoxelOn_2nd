# 락온 조준점 하향 편향 검토

## 원인과 수정

기체 루트는 지면 높이에 놓이는데, 실제 LOCK 무기 사격 방향은 적의 루트 위치를 향하고 있었습니다. 조준 가능 여부와 화면 표식은 루트보다 1.2m 위를 검사해 사격 방향과 표시 위치도 서로 달랐습니다. 일부 프레임은 렌더러 경계 중심이 루트보다 낮게 계산되어 같은 문제를 더 키울 수 있습니다.

LOCK 조준점 계산을 지면 기준 루트에서 1.2m 위의 공통 지점으로 통일했습니다. 발사 방향, 시야/엄폐 검사, 락온 표식이 같은 지점을 사용합니다. 조준점이 대상의 수직 이동을 따라가는 검사도 추가했습니다.

## 실제 검증

- Unity 6000.6.7f1 Windows 빌드: 성공 (`VOXSKY_BUILD_PASS 237474818 bytes`).
- Arena 씬 및 PD 밸런스 데이터는 빌드 전후 SHA-256이 동일했습니다.
- Windows 플레이어 ControlReview: 락온 높이/이동 및 표식 높이 검사 4개 통과. 전체 25개 중 24개 통과; 별도의 기존 다리 앵커 검사 1개 실패로 프로세스 종료 코드는 2였습니다. 이 다리 검사는 이번 락온 변경 범위가 아닙니다.
