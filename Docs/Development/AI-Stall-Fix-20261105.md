# 2026-11-05 AI 벽 정지 수정

박PD가 제보한 ‘벽에 붙거나 이동 중 가만히 멈춤’을 현재 조작 수정본에서 재현했습니다. 기존 사용자 변경을 유지하고, 정상 실행본/AI 소스를 `Backups/AI-Stall-20261105/`에 보존했습니다.

## 확인한 원인과 수정

AI의 일반 이동 후보와 EscapeHeading이 장애물만 검사하고 실제 경기장 경계는 검사하지 않았습니다. 경계에 붙어 있을 때 경기장 바깥으로 향하는 탈출점이 선택될 수 있었고, 실제 Move의 경계 클램프와 충돌해 정지가 반복됐습니다.

- 두 이동 후보 경로에 기체 반경을 포함한 경기장 내부 검사를 추가했습니다.
- 막힘 감지는 전체3D 속도 대신 수평 속도로 판단합니다. 벽 앞 제자리 점프를 수평 탈출로 잘못 계산하지 않습니다.
- 탈출 방향을 골랐다는 이유로 stuckTime을0으로 만들지 않고 실제 수평 움직임이 생겼을 때 해제합니다.
- 순간이동, 충돌 삭제, 속도/난이도/명중률 강화 없이 기존 이동·점프·엄폐 경로를 유지합니다.

## 재현과 결과

실제 Windows 실행본에서 경계 평행 이동, 긴 벽 밀착, U자 엄폐의9상황을3기체로 검사했습니다. 초기57개 중5개가 실패했습니다: 경기장 밖 탈출점3개, WISP/TARANTULA의 긴 정지2개입니다. 긴 벽과 U자 상황은 기존에도 통과했으므로 새로 고쳤다고 과장하지 않습니다.

| 경계 상황 | 이전 최장 정지 | 이후 |
| --- | --- | --- |
| WISP | 2.64초 | 0.00초 |
| BASTION | .24초 | .02초 |
| TARANTULA | 2.88초 | 0.00초 |

수정 후57개 전체 통과, 9상황 최장 정지는 .34초 이하였으며 모두 시야를 회복하고 충돌 침투 없이 이동했습니다. 이것은 고정50Hz/각30초의 총270초 **게임 시뮬레이션**이며 벽시계270초/사용자 수동 플레이는 아닙니다.
