# 2·3번 기체 락온 프레임 정렬 — 2026-11-06

박PD가 보고한 락온 커서와 상대 기체를 둘러싼 표식의 위치 차이를 수정했습니다.

## 원인과 수정

기존 잠금 조준 표식은 기체 루트 위의 고정 좌표(`root + Y 1.3m`)를 썼고, 감싸는 표식은 루트 좌표와 프레임별 임의 크기 수치로 계산했습니다. 모델마다 실제 메시 크기·관절 포즈가 달라 두 표식이 시각적으로 어긋났습니다. 잠금 조준 표식에는 위치 보간 지연도 있었습니다.

이제 두 표식 모두 실제 기체의 활성 Renderer 경계 상자를 화면 좌표로 투영해 같은 기준을 사용합니다. 무장과 방패는 몸체 경계에서 빼고, 프레임 크기에 맞춰 바깥 여백을 줍니다. 잠금이 움직일 때 표식도 같은 프레임의 투영 위치를 따라갑니다. 전투 타깃·조준 방향·락온 규칙은 바꾸지 않았습니다.

## 확인

- Unity 6000.6.7f1 Windows 빌드: `VOXSKY_BUILD_PASS 237209018 bytes`.
- 실제 Windows 게임 Control Review: **20 checks 통과**. BASTION과 TARANTULA 각각 실제 기체 Renderer 경계에서 동일 락온 사각형이 생성되는지 확인.
- 실제 화면 캡처를 확인함: `../Screenshots/Weapons-20261105/Controls/lock-frame-BASTION.png`, `lock-frame-TARANTULA.png`. 두 기체 모두 상대 기체를 감싸는 경계와 잠금 중심표식이 같은 모델 경계 주위에 표시됨.
- 최신 전체 스모크: **358 checks 통과** (`Logs/LockFrame-v002-Smoke.log`).

수동 마우스 조작 체감은 박PD가 최신 실행본에서 확인할 항목입니다. 외형 프레임은 실제 관절 움직임으로 바뀌므로 점프/강한 포즈 전환에서 최종 체감 확인은 남습니다.
