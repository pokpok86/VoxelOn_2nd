# 시스템 확장 30분 작업 — 3차 설계 슬롯 복사·초기화

작성: 2026-11-06. 작업 기준은 `work`에서 분리된 현재 작업 트리다. `main`은 변경/병합하지 않았고, 이 작업은 아직 커밋·푸시하지 않았다.

## 구현

- 행거의 장착 탭에 현재 설계 슬롯 복사, 선택 슬롯에 붙여넣기, 선택 슬롯 기본값 초기화를 추가했다.
- 복사 내용은 편집기 세션 중 임시 보관된다. 붙여넣을 때 대상 슬롯 ID와 선택 상태는 유지하고, 설계 이름·기체 종류·4개 장착 정보를 복사한다.
- 초기화는 현재 선택한 슬롯만 기본값으로 되돌린다. 저장 파일은 자동 변경하지 않으며 저장 버튼을 눌러야 디스크에 반영된다.
- 데이터 복사 시 배열을 새로 만들어 소스/대상 간 별칭이 생기지 않도록 했다. 알 수 없는 슬롯 초기화 요청은 거부한다.
- 실제 UI 캡처를 검토한 뒤 장착 위치 선택과 중복되던 무기 제목을 제거했다. 캡처: `Docs/Screenshots/Balance-Editor-20261106/SchemaV3-Iteration3/03b-design-slot-management.png`.

## 제한과 다음 단계

- 파츠 수치는 아직 기체 종류별 공용 한 벌이며 저장 설계 슬롯마다 독립되지 않는다. 복사/초기화도 현재 무장과 기체 선택만 다룬다.
- 다음에는 파츠 정의를 슬롯별 override로 분리하고 v3 저장 파일을 안전하게 이전한다. 각 슬롯의 수치를 실제 기체에 적용하고 슬롯 사이 독립성, v1/v2/v3 migration, 파일 백업을 자동 검사한다.
- 새로운 무기/파츠 ID를 정의만으로 등록하는 확장 카탈로그와 실제 런타임 반영은 아직 미완료다.
- Windows 빌드와 자동 검사는 통과했지만, 박PD의 직접 플레이/UX 승인은 대기 중이다.
