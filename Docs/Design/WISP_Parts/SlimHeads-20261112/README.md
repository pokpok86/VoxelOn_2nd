# 슬림·장형 머리 비교 후보

PD의 “더 얄쌍하고 기다란 타입” 요청에 대한 두 방향의 신규 디자인 초안이다. 별도 컨셉 이미지를 제공받은 모델은 아니다. 길이 방향에 대한 PD 선택과 디자인 승인은 대기 중이다. 기존 머리 4종은 수정하지 않았다.

- H-05 NEEDLE: 앞뒤로 길고 납작한 좁은 센서 헤드, 긴 측면 장갑, 한 줄 바이저.
- H-06 LANCET: 정면에서 세로로 길고 갸름한 얼굴, 좁은 이마와 아래로 좁아지는 턱, 한 줄 바이저.

목 자체를 늘리지 않고 기존 짧은 연결부를 유지했다. 외장이 목에서 떨어져 보이지 않도록 외장 위치를 맞췄다. Blender 5.2.3에서 파일을 다시 열어 기존 목 접촉면과 목~외장 사이 틈을 검사했고 두 모델 모두 통과했다. 원본 베이스 9개 파일의 해시도 유지했다. 이는 정적 Blender 검증이며, 게임 적용·가동 검사·디자인 승인을 뜻하지 않는다.

| 후보 | 전체 폭(m) | 앞뒤 깊이(m) | 전체 높이(m) |
|---|---:|---:|---:|
| H-05_NEEDLE | 0.074 | 0.152 | 0.076 |
| H-06_LANCET | 0.067 | 0.068 | 0.137 |

각 폴더에 편집 가능한 단독/장착 .blend, 정면·우측·후면·좌측·45도·목 확대·장착 PNG를 보관한다. 총 Blender 파일 4개와 기본 렌더 14개이다.

[휴대폰 비교 이미지](Slim-Heads-Review-Phone.png) · [기존 몸통 장착](Slim-Heads-Mounted-Phone.png) · [검사 결과](Validation.json)

재생성은 기존 제작 도구에 `--part H-05_NEEDLE` 또는 `--part H-06_LANCET`를 전달한다. 검사는 `verify_head_core_family.py --slim`으로 실행하며 Blender의 `--python-exit-code 1` 옵션을 함께 사용한다.
