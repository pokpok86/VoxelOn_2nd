## 덕트와 형태

사진의 외곽 실루엣과 큰 장갑 덩어리를 먼저 재현합니다. 백팩은 사진처럼 진한 회색/남색과 주황·붉은 내부 발광을 사용하고, 하체는 기존 소체와 같은 밝은 장갑/흑연색 관절/청록 발광을 사용합니다.
덕트는 실제로 장갑을 파내고, 입구 챔퍼·내벽·안쪽 발광부·내부 분할을 가진 중공 구조입니다. 비스듬한 시점에서 막힌 검정 구멍처럼 보이지 않도록 내부 벽에도 발광 구간을 넣었습니다. 원래 그림에서 보이지 않는 내부 고정·접이 기구는 모델링 가정입니다.
그림은 CAD 도면이 아니므로 각 뷰가 다를 때 대표 45도/정면 실루엣을 우선합니다. **원본과 정확히 동일하거나 디자인 승인되었다고 단정하지 않습니다.**
