2026-11-12 PD가 W-01 LUMEN에 대해 “이정도면 합격다음꺼는 5개 한방에”라고 승인·요청했습니다. 아래 다섯 후보를 제작했습니다. **W-01의 승인은 기록했고, 새 5종의 디자인 승인은 각각 대기 상태입니다.**

## 제출 자료

각 폴더에 단독 `.blend`, 소체 복사본을 불러온 별도 장착 검토 `.blend`, 동일 정사영 배율의 정면·측면·후면·45도 PNG, 공통 연결부 확대, 장착 미리보기, 원본과의 세로 비교판, README, manifest가 있습니다.

모아 보는 이미지: `FirstBatch-Five-Review-Phone.png`. 파츠별 `*-Review-Phone.png`는 컨셉 이미지의 45도 크롭과 실제 렌더를 나란히 보여줍니다. 비교판의 크롭은 독립적으로 확대하므로 치수 검토는 원본 렌더와 manifest를 사용합니다.

팔 4종은 승인된 LUMEN의 팔꿈치 원점·축·접속 형상을 공통 사용합니다. 손, 손가락, 손목, 손잡이는 추가하지 않았습니다. 백팩 연결판과 핀은 기존 몸통 후면판을 기준으로 한 잠정 제작용 가정이며, 내부 잠금 방식은 확정하지 않았습니다.

## 실제 수행한 검증

- Blender 5.2.3 LTS에서 5종을 생성하고 실제 PNG를 렌더했습니다.
- 저장한 단독 `.blend` 5개를 다시 열어 오브젝트 ID, 파츠별 메시 수, 연결 원점과 네 정사영 카메라의 공통 배율을 검사했습니다. 결과: `FirstBatch-Validation.json`.
- 대기·조준 자세(방패는 대기·가드)에서 선택한 주요 외피와 몸통·허벅지의 경계 상자 간섭을 검사했습니다. 백팩은 장착된 대기 자세를 검사했습니다.
- 백팩 양쪽 발광 코어가 노즐 축 방향에서 가려지지 않는지 광선 검사로 확인했습니다.
- 참고 PNG의 SHA-256과 기존 BD-01·HD-01·LG-01 원본 `.blend`의 전후 SHA-256을 확인했습니다. 원본 소체는 수정하지 않았습니다. 백팩 장착 화면의 LUMEN 역시 승인된 파일을 복사해 사용했습니다.
- 생성 이미지와 비교판을 열어 검토했습니다. 포구 벽의 겹침, 부스터 광원 가림, EDGE 하박의 얇은 두께, 부스터 후드 범위를 수정한 뒤 해당 파츠를 다시 렌더했습니다.

## 검토할 차이 및 제한

자동화 검사는 디자인 승인과 다릅니다. 장갑 분할과 재질은 원본보다 단순하며, 숨은 내부는 제작 가정입니다. 백팩은 노즐 돌출로 참고 그림의 숫자보다 앞뒤 깊이가 큽니다. 그림도 검증된 CAD가 아니므로 실제 연결·장착 크기는 PD 검토 대상입니다.

정적 경계 상자 검사는 모든 삼각형의 자기 교차, 전체 관절 애니메이션, 물리 충돌을 보증하지 않습니다. Unity 적용·게임 빌드·성능 수치·밸런스 변경은 수행하지 않았습니다. 기존 미커밋 게임 작업과 PD 수치, Arena 씬은 그대로 보존했습니다.
