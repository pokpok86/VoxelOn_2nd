# B-02_SKYWING — 날개형 부스터

PD가 승인한 163cfa5의 소체 크기·비율·디자인 계열을 고정한 신규 후보입니다. 별도의 개별 컨셉 그림은 제공되지 않아, 원본 그림 재현이 아닌 같은 계열의 확장 디자인입니다. **디자인 승인 대기**입니다.

형태: 위로 벌어진 후퇴익, 아래쪽 소형 분사구, 낮은 매립 방열구. 기존 회색/아이보리 장갑, 흑연색 구조물, 주황 포인트, 청록 발광을 유지합니다. 덕트는 돌출 블록 대신 낮은 방열구로 제작했습니다.

## 결과 파일

- `B-02_SKYWING.blend`: 다른 소체 파츠가 섞이지 않은 단독 수정 원본.
- `B-02_SKYWING-Mounted-Review.blend`: 승인 소체와 기존 LUMEN을 장착한 검토 장면.
- `01-Front`, `02-Right`, `03-Rear`, `04-45deg`, `05-Top`: 같은 정사영 배율의 5방향 PNG.
- `06-Mount-Closeup`: 공통 접속부 확대.
- `Mounted-Front`, `Mounted-Rear`: 실제 조립 모습.
- `B-02_SKYWING-Review-Phone.png`: 휴대폰용 세로 검토 이미지.
- `manifest.json`: 규격·치수·기준 파일 해시·실제 검사 및 제작 가정.

## 연결과 검증 범위

기존 B-01과 같은 등 뒤 접속판/핀 간격을 사용하며, 기준 몸통 뒤쪽 접속 좌표에 배치합니다.
보이지 않는 고정장치, 날개의 가동 방식, 하체의 자세는 제작용 가정입니다. 다리와 궤도·팬은 시각적 분리 모델이며, 보행·주행·호버 작동이나 게임 적용은 구현/검증하지 않았습니다.

Blender 5.2.3에서 이미지/원본 생성 및 저장 파일 재개방, 접속 규격, 기준 소체 9개 원본의 SHA-256 보존을 검사합니다. 실제 결과는 `../Expansion-Validation.json` 기준입니다. Unity 작업과 성능 수치 변경은 없습니다.

재생성: `Tools/build_expansion_part.py -- --part B-02_SKYWING`를 Blender 백그라운드 Python으로 실행합니다.
