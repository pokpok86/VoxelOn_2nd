# B-01_TWIN_DRIVE — 기본 부스터 디자인 검토 후보

2026-11-12 PD가 W-01 LUMEN을 승인하고 다음 5종의 묶음 제작을 요청했습니다. **이 파츠의 외형·연결부 승인은 대기 중입니다.** 성능 수치·게임 밸런스·Unity 변경은 포함하지 않습니다.

## 형상과 가정

참고: `../References/B-01_TWIN_DRIVE.png`. 우선 재현한 특징은 좌우 대칭 추진기, 중앙 연결 등뼈, 위쪽 흰 후드와 후면 냉각구, 아래·뒤로 향하는 청록 노즐입니다.

기존 몸통 후면판에 맞춘 공통 접속판과 4개 핀은 잠정 제작용 가정입니다. 내부 잠금 구조는 확정 규격이 아닙니다.

잠정 몸통 후면 기준점은 정규화 소체의 `(0, 0.11398, 0.67244)`입니다. 기존 후면판 위에 접속판을 배치하고 백팩 원본은 유지했습니다. PD 요청으로 몸통이 0.82배로 줄어 현재 접속 위치도 함께 이동했습니다. 백팩의 노즐 돌출을 포함한 앞뒤 깊이는 참고 그림의 숫자보다 크므로 장착 크기는 PD 검토 대상입니다.

작업 좌표는 X=폭, Y=앞뒤, Z=높이입니다. 실제 생성 외곽은 **0.377 × 0.2327 × 0.2705 작업 단위**입니다. 참고 치수는 검증된 CAD 수치가 아닙니다. 정면과 45도 윤곽을 우선했고, 시점별 모순과 숨은 구조는 원본의 정밀 설계로 확정하지 않았습니다.

## 파일

- `B-01_TWIN_DRIVE.blend`: 해당 파츠 단독 편집 원본. 장갑·골격·연결부가 분리되어 있고 물체 이름에 파츠 ID가 들어갑니다.
- `B-01_TWIN_DRIVE-Mounted-Review.blend`: 기존 소체를 복사해 불러온 별도 장착 검토 장면.
- `B-01_TWIN_DRIVE-01-Front.png` ~ `04-45deg.png`: 정면·우측·후면·45도. 네 원본 렌더는 파츠별 동일한 정사영 배율입니다.
- `B-01_TWIN_DRIVE-05-Mount-Closeup.png`: 공통 연결부 확대.
- `B-01_TWIN_DRIVE-Mounted-idle.png` (승인된 LUMEN을 함께 표시한 후면 기체 미리보기).
- `B-01_TWIN_DRIVE-Review-Phone.png`: 컨셉 45도와 실제 렌더의 비교 및 검수 이미지 모음. 비교용 크롭은 독립적으로 확대합니다.
- `manifest.json`: 경계 치수, 장착 좌표, 검사 결과, 소체 원본 해시와 가정.

EDGE와 AEGIS의 정면·후면은 포구 방향이 아닌 넓은 장갑 면의 +Z/-Z 방향입니다. 백팩 정면은 몸통 접속판 쪽(-Y), 후면은 냉각구·노즐 쪽(+Y)입니다.

## 실제 검증 및 한계

Blender 5.2.3 LTS에서 생성·렌더를 실행했습니다. 장착 자세에서 선택한 주요 외피와 몸통·허벅지의 경계 상자 간섭을 검사했고, 기존 BD-01·HD-01·LG-01 원본 파일의 전후 SHA-256 일치를 확인했습니다. 이는 전체 관절 애니메이션, 정밀 삼각형 충돌, 모든 부품의 자기 교차나 게임 검증을 의미하지 않습니다. 백팩 노즐은 두 발광 코어의 축 방향 가시성도 검사합니다.

자동화 PASS / **PD 디자인 승인 PENDING** / Unity 미실행. 앞·옆·뒷면의 장갑 두께와 분할, 연결부의 상세 구조·재질은 원본보다 단순한 검토 후보입니다.
