- 6종 장착 미리보기와 세로 검토 이미지를 갱신. 몸통 전후 비교는 같은 카메라와 배율 사용.

## 실제 수행한 검증

Blender 5.2.3에서 몸통 생성 및 어깨 앞뒤 회전·벌림, 허리 회전 검사 통과.
6종 조립에서 허리/목 접촉 오차 각각 0 / 약 0.00000006 m. 대기/조준 또는 가드 자세에서 주요 무장 외곽과 몸통/허벅지 경계상자 간섭 검사 통과.
5종 저장 원본 재개방, 메시 수·연결 원점·참고 이미지 해시·정사영 배율 확인 통과.
실제 생성된 LUMEN 장착 및 전후 비교 이미지를 열어 크기 변화를 확인함.

수치 결과는 `Body-Size-Validation.json`. 정적 검증이며 동작 중 충돌이나 Unity 검증을 의미하지 않음. 디자인 승인은 PD 확인 대기.
