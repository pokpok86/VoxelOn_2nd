# WISP 머리·몸통 신규 후보 8종

2026-11-12 PD 제공 이미지 기준 **Blender 1차 검토안**. 기존 WISP 원본과 게임 적용 모델은 덮어쓰지 않았다. 디자인 승인은 PD 검토 대기이며, 이번 신규 8종은 아직 Unity에 연결하지 않았다.

| 구분 | 파츠 |
|---|---|
| 머리 | H-01 RADOME, H-02 LONGSIGHT, H-03 SWIFTFIN, H-04 BULWARK |
| 몸통 | C-01 STANDARD, C-02 LIGHTFRAME, C-03 BULWARK CORE, C-04 ARC CORE |

각 폴더에는 편집 가능한 단독 `.blend`, 기존 소체에 장착한 `-Mounted.blend`, 정면·우측·후면·좌측·45도 PNG, 연결부 확대, 세로형 장착 PNG, 원본 컨셉 비교 이미지가 있다. 제공 JPG 8장은 References에 원본 바이트 그대로 보관하고 Reference-Manifest.json에 SHA-256을 기록했다.

## 제작 기준과 조정

- 기존 기체의 몸통/머리/다리/무장 원본 9개는 해시로 보존 확인했다. 연결 기준은 승인된 BD01의 목 접촉면·허리 접촉면·양쪽 어깨/팔꿈치 중심을 사용했다.
- 몸통에는 PD 요청대로 상박을 추가했다. 승인된 BD01의 짧은 상박과 팔꿈치 핀을 복사하여 하박 무장 교체 지점을 유지했다. 어깨 회전부와 몸통 사이의 연결도 연속되도록 구성했다.
- 신규 머리는 짧은 공통 목 연결부를 사용한다. 레이돔/렌즈/핀/중장갑 턱의 차이가 읽히도록 실루엣을 구분했다. 첫 렌더에서 과도했던 레이돔 폭과 핀 높이를 줄이고, 둥글게 보이던 이마를 평면·경사면으로 수정했다.
- 몸통은 표준 판형 가슴, 좁은 V형 경량 가슴, 두꺼운 중장갑 가슴/복부, 노출형 아크 코어로 구분한다. 장식 상자를 늘리는 대신 가슴과 어깨 장갑의 면을 나누고 실제 앞뒤 돌출을 만들었다.
- 참고 이미지에 없는 후면은 공통 장착면과 단순 폐쇄 패널을 사용한 제작 가정이다. 렌즈의 광학 동작, 핀/레이돔 가동, 성능 수치, 추가 전투 규칙은 임의로 정의하지 않았다.

## 검증과 한계

Blender 5.2.3 LTS로 생성·저장·렌더 후 파일을 다시 열어 검사했다. 목·허리 접촉면 및 몸통 4종의 좌우 팔꿈치 중심은 기존 값과 0.00001m 이내에서 일치한다. 단독/장착 Blender 16개와 기본 렌더 64개, 비교 이미지 8개를 확인했다. 상세 결과는 Validation.json, 실행 출력은 Verification.log에 기록한다.

이는 정적 파일·연결 위치 확인이며, 새 8종의 게임 내 가동/장갑 충돌/성능 검증 완료를 뜻하지 않는다. 이전 게임의 관절 검사 결과를 이번 미적용 모델의 검증으로 재사용하지 않았다. 제공 컨셉과의 최종 유사도 및 비율 승인은 PD가 결정한다.

## 몸통 실루엣 후속 수정

PD가 몸통과 어깨 외곽으로 구분되기를 요청하여 4종 어깨 윤곽을 각각 다시 설계했다. 기존 캡 하나를 크기만 조절하는 방식은 제거했다.

- STANDARD: 낮고 균형 잡힌 사각 어깨와 짧은 판형 몸통.
- LIGHTFRAME: 좁은 V형 몸통, 얇고 바깥으로 깎인 쐐기형 어깨, 작은 복부/옆 장갑.
- BULWARK CORE: 넓고 깊은 몸통, 아래로 겹쳐 덮는 두꺼운 대형 어깨, 넓은 복부와 옆 장갑.
- ARC CORE: 높은 갈라진 어깨, 분리된 아래 장갑, 후면의 짧은 요크, 코어를 감싼 하단 외곽.

목·허리·팔꿈치 위치와 기존 짧은 상박은 유지했다. 머리 4종 및 게임 코드는 수정하지 않았다. 변경 전 몸통 후보는 PC 임시 백업에 보존했다. Blender 파일을 다시 열어 연결부를 재검사했고 모두 기존 기준과 일치했다.

몸통 정면/측면은 모두 0.70m의 동일한 촬영 크기와 같은 중심에서 렌더했다. 색상과 세부 장식의 영향을 제거한 검은 실루엣도 추가했다. 쌍별 마스크 비교 결과는 Silhouette-Validation.json이며, 이 수치는 디자인 승인이나 형태의 우수함을 의미하지 않는다. 새 모델의 게임 적용 및 움직임 검사는 아직 하지 않았다.
