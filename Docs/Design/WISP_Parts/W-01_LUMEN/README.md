- `W-01_LUMEN-01-Front.png`~`04-45deg.png`: 정면·우측·후면·45도. 네 카메라 모두 동일한 정사영 크기 0.96을 사용합니다.

- `W-01_LUMEN-Mounted-idle.png`, `Mounted-aimed.png`: 팔을 내린 상태와 전방 조준 상태.

- `manifest.json`: 원본 파일 해시, 장착 기준점, 배율, 검사 결과와 가정.

## 형태와 연결 기준

참고 이미지는 `../References/W-01_LUMEN.png`입니다. 앞쪽의 긴 검은 포신, 중앙·후방의 각진 장갑, 주황색 앞 장갑, 하단의 한 줄 발광창, 뒤쪽 위로 솟은 원통형 팔꿈치 소켓을 우선 재현했습니다. 손·손목·손잡이는 없습니다. 물체 이름에 `W-01_LUMEN` 접두사가 붙습니다.

작업 좌표는 X=폭, Y=앞뒤(포구는 -Y), Z=높이입니다. 팔꿈치 축은 X이며 중심은 작업 좌표 `(0, 0.282, 0.109)`입니다. 외곽은 약 **0.214 × 0.709 × 0.277 작업 단위**로 그림의 참고 치수에 가깝게 잡았습니다. 정확한 CAD 치수로 확정한 값은 아닙니다.

기존 WISP는 약 1 높이로 정규화된 별도 기준이므로 장착 미리보기에서는 무장을 균일하게 **0.42배**로 축소했습니다. 몸통 축소 후 팔꿈치 위치는 정규화된 기체의 약 `(±0.23124, 0, 0.58798)`이며 현재 manifest의 assembly_layout에서 계산합니다. 이 배율과 외형은 PD 검토 대상입니다. 최초 제작에서는 소체 원본을 보존했습니다. 이후 PD의 몸통 크기 조정 요청으로 BD01만 0.82배로 줄였고, 머리·다리 및 LUMEN 원본은 유지했습니다.

## 실제 확인한 내용과 한계

Blender 5.2.3 LTS에서 생성·렌더를 실행했습니다. 기존 세 `.blend` 파일의 실행 전후 SHA-256 일치를 확인했습니다. 팔을 내린 자세와 전방 조준 자세에서 주요 무장 외피의 경계 상자와 몸통·허벅지 경계 상자가 겹치지 않는지 검사했습니다. 접합부의 의도된 맞물림은 이 검사 대상이 아닙니다. 전체 관절 애니메이션·정밀 충돌·게임 동작 검증은 하지 않았습니다.

그림의 정면·측면·45도는 서로 완전히 일치하는 설계도가 아닙니다. 정면과 45도 외곽을 우선했고, 보이지 않는 소켓 내부 체결·포신 내부는 가정해서 구성했습니다. **자동 생성 성공과 디자인 승인은 구분합니다.** 이 후보는 이후 2026-11-12 대화에서 PD 승인을 받았습니다. 후속 5종은 별도로 디자인 검토를 받습니다. Unity 연동은 하지 않았습니다.
