# 원통 관절 직결 장착 — 2026-11-12

PD 요청: 원통 관절과 무기 사이의 비스듬한 막대를 없애고 무기가 원통부터 바로 이어지게 조정.

- 장착 검토 모델에서 LUMEN의 Elbow_Offset_Bridge와 나머지 4종의 Common_Offset_Link 제거.
- 무기 본체 중심을 관절의 중심선에 정렬하고 뒤쪽 코어 면을 원통 표면에 직접 맞춤.
- 무기 크기(유효 배율 0.819), 칼/방패 본체의 좌우 90도 회전 및 원통 관절의 로컬 형상/치수는 유지.
- 본체가 관절에 가까워져 기존 자세에서 몸통/허벅지 경계상자 간섭이 발생. 검토용 어깨 벌림은 20→30도로 조정하고 대기 각도는 50도 유지. 총기 조준 검토는 30도 기울인 자세, 칼은 0도, 방패 가드는 90도에서 간섭 없음 확인.
- 몸통/머리/다리와 단독 무장·백팩 원본 .blend는 보존. 수정 결과는 각 파츠의 Mounted-Review.blend와 장착 PNG에 저장. 원본과 독립적인 장착 보정 도구에 직결 규칙을 반영했으므로 재생성 가능.

## 실제 검증

Blender 5.2.3에서 장착 6개 조합의 대기·조준/가드 이미지 및 검토 .blend 재생성.
저장된 장착 모델 6개 재개방: 제거한 막대 이외의 메시 유지, 남은 연결 링/소켓의 로컬 변환 유지, 무기 본체의 3×3 변환(크기/방향) 동일 확인.
무기 코어 뒤쪽 면과 관절 축 사이 거리는 14.7 mm로, 원통 반경 26.04 mm 안에 들어가 직접 맞물림 확인. 장착 루트와 몸통 팔꿈치 핀의 중심 일치.
목/허리 접촉 오차 0, 선택된 검토 자세의 주요 외곽 경계상자 간섭 없음.
실제 LUMEN·AEGIS 장착 이미지를 열어 막대가 사라지고 관절에서 곧바로 이어지는 모습 확인.

기록: Direct-Mount-Validation.json 및 최신 Weapon-Mount-Validation.json. 이전 검증 기록은 당시 변경 이력이며 현재 판정은 이 두 파일 기준. 디자인은 PD 확인 대기. Unity/게임 수치 변경 없음.
