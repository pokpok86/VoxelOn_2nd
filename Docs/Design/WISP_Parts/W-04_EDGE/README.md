# W-04_EDGE — 근접 블레이드 디자인 검토 후보

2026-11-12 PD가 W-01 LUMEN을 승인하고 다음 5종의 묶음 제작을 요청했습니다. **이 파츠의 외형·연결부 승인은 대기 중입니다.** 성능 수치·게임 밸런스·Unity 변경은 포함하지 않습니다.

## 형상과 가정

참고: `../References/W-04_EDGE.png`. 우선 재현한 특징은 하박 중심 골격에서 곧바로 이어지는 칼날, 중앙 능선과 양쪽 절삭면, 흰 측면 장갑입니다.

칼날의 보이지 않는 뒷면 두께와 에너지 경계 단면은 가정입니다. 손잡이·손목은 없습니다.

승인된 W-01 LUMEN의 팔꿈치 원점 `(0, 0.282, 0.109)`, X 회전축, 드럼과 소켓 치수를 공통 사용합니다. 장착 미리보기에서는 기존 정규화 소체에 맞춰 0.42배로 표시합니다.

작업 좌표는 X=폭, Y=앞뒤, Z=높이입니다. 실제 생성 외곽은 **0.192 × 0.9515 × 0.2318 작업 단위**입니다. 참고 치수는 검증된 CAD 수치가 아닙니다. 정면과 45도 윤곽을 우선했고, 시점별 모순과 숨은 구조는 원본의 정밀 설계로 확정하지 않았습니다.

## 파일

- `W-04_EDGE.blend`: 해당 파츠 단독 편집 원본. 장갑·골격·연결부가 분리되어 있고 물체 이름에 파츠 ID가 들어갑니다.
- `W-04_EDGE-Mounted-Review.blend`: 기존 소체를 복사해 불러온 별도 장착 검토 장면.
- `W-04_EDGE-01-Front.png` ~ `04-45deg.png`: 정면·우측·후면·45도. 네 원본 렌더는 파츠별 동일한 정사영 배율입니다.
- `W-04_EDGE-05-Mount-Closeup.png`: 공통 연결부 확대.
- `W-04_EDGE-Mounted-idle.png` 및 `W-04_EDGE-Mounted-aimed.png`.
- `W-04_EDGE-Review-Phone.png`: 컨셉 45도와 실제 렌더의 비교 및 검수 이미지 모음. 비교용 크롭은 독립적으로 확대합니다.
- `manifest.json`: 경계 치수, 장착 좌표, 검사 결과, 소체 원본 해시와 가정.

EDGE와 AEGIS의 정면·후면은 포구 방향이 아닌 넓은 장갑 면의 +Z/-Z 방향입니다. 백팩 정면은 몸통 접속판 쪽(-Y), 후면은 냉각구·노즐 쪽(+Y)입니다.

## 실제 검증 및 한계

Blender 5.2.3 LTS에서 생성·렌더를 실행했습니다. 장착 자세에서 선택한 주요 외피와 몸통·허벅지의 경계 상자 간섭을 검사했고, 기존 BD-01·HD-01·LG-01 원본 파일의 전후 SHA-256 일치를 확인했습니다. 이는 전체 관절 애니메이션, 정밀 삼각형 충돌, 모든 부품의 자기 교차나 게임 검증을 의미하지 않습니다. 백팩 노즐은 두 발광 코어의 축 방향 가시성도 검사합니다.

자동화 PASS / **PD 디자인 승인 PENDING** / Unity 미실행. 앞·옆·뒷면의 장갑 두께와 분할, 연결부의 상세 구조·재질은 원본보다 단순한 검토 후보입니다.
