## 비교하며 발견하고 고친 문제

새 외장을 단순 장식으로 덧붙이지 않았습니다. 반복01→06의 실제 Unity 같은 각도 비교와 박PD Reference-5 대조를 남겼습니다. 상자 같은 차체/후드를 경사·챔퍼로 바꾸고 탱크 손 가림, 사족 캡처 다리 잘림, 무릎 호스 연결을 개선했습니다.

첫 메시 예산 실패, WISP 버전 화이트리스트에 따른 리그 인식 실패, AI 우회 추가로 생긴 기존 점프 회귀, 궤도 스폰 위상 실패를 실제로 재현하고 수정했습니다. 실패 테스트를 삭제하거나 기준을 완화하지 않았습니다. 호스 검사에서는 임의 정점 하나 대신 동일한 고정 끝 영역 전체를 계측하도록 fixture를 바로잡았으며 .02m 기준을 유지했습니다.

실제 F2 화면을 열기만 해도 방패 페널티가 .02→.05로 바뀌던 슬라이더와 사용되지 않는 좌우 이동 값을 편집하던 연결, 스크롤/날씨 버튼 겹침도 수정했습니다. 연기 발생 자체와 일반 후방 시점 가독성을 구분하여 성숙 단계까지 촬영한 뒤 크기/상승을 조절했습니다.
