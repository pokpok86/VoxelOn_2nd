# WISP 전용 플레이테스트: 시점·조준점·양손 입력

2026-11-03. 이전 v003 모델/기존 로컬 수정 위에 적용했습니다.

## 현재 플레이 흐름

- 격납고에는 WISP 한 기체만 표시합니다. 플레이어, 고정/랜덤 AI 상대, AI 관전 출격 모두 WISP로 제한합니다.
- BASTION/TARANTULA/HOUND 정의와 내부 회귀 검사 데이터는 보관합니다. 외형과 움직임이 함께 준비되고 승인된 후 `CraftCatalog.UnlockedCount`를 늘려 공개합니다.
- 기존 저장 설정에서 잠긴 기체를 선택했더라도 WISP로 안전하게 전환합니다.
- WISP는 완전 수동 조준입니다. 좌클릭은 왼손 총, 우클릭 유지는 오른손 방패를 정면으로 올리는 자세입니다. 마우스를 놓으면 부드럽게 내려옵니다. WISP에서는 숫자 슬롯 변경을 사용하지 않으며, 과거 특수 무장 데이터/직접 회귀 검사 경로는 보관합니다.
- 오른팔 어깨·팔꿈치의 실제 관절을 회전시키고, 방패 면이 정면을 향하도록 유지합니다. 총은 왼손, 방패는 오른쪽 팔꿈치 아래 `RIGHT_SHIELD_SOCKET`에 장착했습니다. 이 소켓은 Unity 연결 단계에서 생성합니다.
- 방패는 이번에 모션만 적용했습니다. 전방 피해 감소·차단·방패 에너지 소비는 추가하지 않았습니다. 기존 자동 실드 게이지는 별도입니다. 화면과 가이드에도 SHIELD POSE로 표시합니다.

## 조준점과 카메라

화면 중앙에 검은 외곽선과 흰색 중심점이 있는 HUD 조준점을 그립니다. 지형·기체에 가려지지 않습니다. WISP의 자동 적 표시 괄호를 제거했습니다.

기체 외형 크기는 유지하고 기본 카메라 궤도 각도를 26도로 높였습니다. 거리를 10.5로 조정하고 앞쪽에 시선을 두어 기체가 화면 아래에 위치하고 전장을 조금 위에서 볼 수 있게 했습니다. 실제 시선 각도는 앞쪽 시선 보정에 따라 궤도 각도보다 낮습니다. 마우스로 시점을 계속 조절할 수 있습니다. 외곽 벽·근접 벽 충돌 및 어깨 시점 회피 처리는 유지합니다.
