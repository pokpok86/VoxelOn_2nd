# WISP v002: 참고 이미지 기반 복셀 외형

2026-11-03. v001의 대체 후보입니다. 기존 게임 연결과 v001 파일은 유지합니다.

## 연결

Root 아래 Head / Core / Arms / Legs / Weapon 이름과 각 관절 이름을 유지했습니다. 기체의 SWORD_SOCKET은 이전 칼을 위한 호환 장착점이며, RIFLE_SOCKET과 같은 손의 같은 위치입니다. SHIELD_SOCKET도 유지했습니다.

주의: v001과 비례 및 피벗 위치가 다릅니다. v001의 좌표를 복사하지 말고 새 모델의 Transform을 찾아 연결하세요. 기존 코드가 수동 변환 보정을 적용했다면 재확인해야 합니다. FBX의 기본 로컬 회전은 0이고 스케일은 1입니다. 무기 FBX의 최상위 오브젝트를 장착점 아래 넣고 위치/회전 0, 스케일 1에서 시작합니다.

Unity 목표: +Y 위, +Z 앞, 1단위=1m. 발바닥 최하단 Y=0. 크기 X 1.7383m × Y 2.7360m × Z 1.1045m. 새 텍스처 파일은 v001과 다른 파일입니다. 기존 게임 재질에 v001 아틀라스가 고정되어 있다면 v002 PNG로 별도 재질을 만들어 연결하세요.

함께 제공한 신규 .meta에는 Preserve Hierarchy 켜기, Bake Axis Conversion 끄기, PNG Point/Clamp/무압축/Mipmap 끄기 설정을 보관했습니다.

## 검증

Unity 6000.6.7f1의 별도 검증 프로젝트에서 기체·라이플·방패를 가져와 계층과 칼·방패 장착점, +Z 전방, 바닥 Y=0, 기본 회전 0, 외부 색상 PNG 연결을 확인했습니다. 실제 게임 플레이와 애니메이션 검증은 아직 하지 않았습니다. 기존 게임 프로젝트의 프리팹/코드는 수정하지 않았습니다.
