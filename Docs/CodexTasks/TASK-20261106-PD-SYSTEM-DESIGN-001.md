## A. 파츠/무기 데이터·커맨드 공통 구조 (우선순위 높음)
- 조립 파츠: 머리, 몸통(코어), 왼팔, 오른팔, 하체, **선택형 백팩**. 백팩 미장착은 가능하나 공중 부스터 없음. 호환 커넥터·제한 사유·즉시 3D 미리보기·저장 설계도 8개.
- 파츠의 기능은 실제 행동과 연결되는 특성 아이콘/레벨 0~5로 설정; 0은 기능 없음. 하체 이동형(이족, 궤도, 사족, 호버), 머리 센서/락온, 팔 반동, 백팩 추진력 등. 모델 외형과 기능 수치 분리.
- 무기는 최대 왼손·오른손·왼어깨·오른어깨 위치, 실제 슬롯은 파츠별 제약. 각 무기 모델은 지정된 장착 위치를 따름. 대표 무기 8종: 소형 라이플, 개틀링, 중형 캐논, 저격 레일건, 플라즈마 캐논, 어깨 미사일 포드, 일체형 캐논 팔, 근접 블레이드. **외형 구별·실제 전투 기능·편집/저장/재시작 검증**을 완료 조건으로 한다.
- 공격력/탄환 수/발사 간격/재장전 시간/질량/반동/열/에너지/특성 등은 데이터로 제어. 탄환 수와 발사 간격 및 재장전 시간으로 연사 패턴을 표현하고 무기별 별도 특수 발사 코드를 남발하지 말 것. 탄환 수와 발사 간격은 서로 다른 값.
- 재장전 능력 0 = 재장전 불가. 소모한 무기는 R 2초 길게 눌러 버림(짧게 R은 가능한 무기의 재장전). 손 무기 버리면 주먹, 어깨 무기는 빈 슬롯; 일체형 무기 팔은 별도 제약. 버린 무기의 질량은 즉시 총중량/운동 성능에서 제외되며, 재출격 시 원래 설계도로 복원.
- 공통 발사/재장전/특수 동작 커맨드와 실행 모듈 분리. 무기 모델·VFX·사운드 바인딩도 데이터로 연결.
- 기본 키: 숫자 1~4는 물리 슬롯 고정이 아니라 **현재 무기 그룹 선택**. 일반적으로 1 왼손/2 오른손/3 왼어깨/4 오른어깨. 양손이 하나의 그룹으로 묶이면 1 양손 그룹/2 왼어깨/3 오른어깨/4 미사용. LMB 기본 공격, RMB는 장착 무기별 특수 동작(가드·줌·락온·차지·없음 등). **두 개 독립 손 무기를 양쪽 클릭으로 운용하는 동시 사용 특성**과 **단일 양손 무기**의 차이는 구현 전 PD 확인; 임의로 RMB 동작을 확정하지 말 것.
- 특성 예: 폭발/호밍/조준보정/락온/차지/근접 등. 외형과 동작을 불필요하게 1:1 고정하지 말 것. 파생 무게·반동·열·에너지 계산은 실제 동작에 반영.

## B. 맵 중력·환경 물리 (우선순위 높음)
- 맵마다 기본 중력값을 가지며 실내 특정 구역에서도 중력값을 동적으로 바꿀 수 있게 설계.
- 중력은 점프 높이·체공·낙하·접지·발사체 궤도·파괴 잔해 등에 공통 물리 계산으로 반영. 단순히 점프 높이 값을 하드코딩해 교체하지 말 것.
- 기체 질량·하체 구동 특성·마찰·부력·저항을 분리. 궤도형은 저중력의 지상 이동 영향이 상대적으로 작되 물리 법칙을 무시하지 않음. 수중은 부력과 유체 저항으로 하강/이동이 달라짐. 호버형은 수면 위 부양 가능. 수중/우주 전체 스테이지 구현은 미래 범위.
- 실내 장애물 중 **중력 제어 장치**를 랜덤 배치할 수 있는 데이터 구조. 파괴되면 경고 메시지 후 중력이 점진적으로 하강; 돌발 가동 시 중력이 증가 또는 감소할 수 있음. 장치 영향 범위, 목표 중력, 변화 속도, 트리거 조건을 데이터화. 시각·사운드 경고 및 HUD 현재 중력값(예: 1.00G→0.65G)과 변화 방향 표시.
- 환경/맵 향후 확장: 실내 파괴 가능 엄폐물과 일부 전기 위험물, 실외 고저차/절벽·고지대, 비·눈·빙판(궤도형 빙판 미끄럼 면역), 수중·호버·우주. **모두 이번에 완성하라는 뜻이 아님**. 공통 물리 계층의 확장성 확보와 대표 검증에 집중.

## C. 파츠 특수 스킬 (대표 예제만 구현)
- 현재 장착된 모든 파츠의 스킬 목록을 스킬창에 표시. 플레이어가 **하나를 Q에 등록**해 사용.
- 게이지는 시간 경과에 따라 자동 충전, **피해를 받으면 추가 충전**; 공격 적중·가한 피해량으로는 충전 보너스 없음. 다단 히트에 의한 충전 폭주 방지. 100%일 때 Q 발동.
- 스킬 효과/배율/대상/지속시간/소모/연출을 데이터화하고 공통 능력치·커맨드에 일시 적용. 대표 예: 공격속도 증가, 재장전 가속, 이동속도 증가, 짧은 무적, 폭발 범위 증가, 즉시/지속 회복·실드 회복, 부스터 에너지 소비 0, 모든 호환 발사체 호밍 부여, 락온/조준 보정 강화. **전체를 다 구현하지 말고 대표 몇 개를 실제 검증**.
- 사용자가 스킬 효과와 맞지 않는 무기 조합을 선택해도 허용. 예: 폭발 범위 강화 스킬 + 폭발 무기 없음 = 발동은 되나 유효 효과 없음. 부스터 무한 + 백팩 없음도 동일.
- 발동 연출: 공격 계열 붉은 화면 테두리, 회복 계열 초록, 이동 계열 잔상 등. **지속시간 숫자/카운트다운은 HUD에 노출하지 않음**. 종료 직전 시각 효과가 점진적으로 약해져 체감 가능. 실제 능력치 효과 종료는 일관되고 테스트 가능하게 처리.
- 스킬 사용이 무기 원본 데이터를 영구 변경하지 않도록 런타임 임시 보정 계층을 분리.
