# VoxSky — 3인칭 지상 로봇 대전 프로토타입

Unity 6.6.7f1 / Windows PC. 로봇 뒤를 따라가는 3인칭 1대1 기동 전투입니다.
8종 프레임, 지상 훈련장, 공통 30발 고속탄 총과 3인칭 조작을 제공합니다. 프레임별 무장 기술은 보관합니다.

## 2026-11-01 후보 작업

Kestrel의 머리·가슴·어깨·발 비율을 키워 SD형 실루엣을 만들고, 바닥과 장애물 충돌 높이를 보이는 모델에 맞췄습니다. 비교 이미지와 검증 결과는 [Kestrel SD·지면 수정 기록](Docs/Screenshots/Work-2026-11-01-Kestrel-SD-Ground/README.md)에서 확인할 수 있습니다. Unity 6000.6.7f1 빌드 성공, Windows 플레이어 스모크 검사 209개 통과, 게임 화면 36장 캡처를 확인했습니다. 변경은 별도 후보 브랜치에 있으며 `main`에는 반영하지 않았습니다.

2026-10-30 빌드 완료. `Builds/Windows/VoxSky.exe`로 실행할 수 있습니다. Windows 폴더 전체를 유지해 주세요.

## 실행

`Builds/Windows/VoxSky.exe`를 실행하고 기체 선택 후 START DUEL 또는 Enter.
다른 폴더나 PC로 옮길 때는 exe만 가져가지 말고 **Windows 폴더 전체**를 복사하세요. Unity 에디터를 열지 않아도 실행할 수 있습니다.
처음에는 메뉴 아래 **AI: PRACTICE / AIM ASSIST: ON**을 그대로 사용하세요.
**HOW TO PLAY / F1**을 누르면 한국어 첫 출격 가이드를 볼 수 있습니다. 전투 중 열면 잠시 멈추며 닫으면 이전 상태로 돌아갑니다. Windows의 맑은 고딕이 없으면 영어 안내로 표시합니다.

| 입력 | 기능 |
| --- | --- |
| WASD | 카메라 기준 이동 |
| Shift 누르기 | 이동 중 부스터 사용; 놓으면 기본 속도로 복귀 |
| 왼쪽 버튼 유지 | 1번 슬롯 고속탄 총 발사 |
| 오른쪽 버튼 유지 | 상대 바라보기 락온; 시야 이탈/엄폐 시 해제 |
| R / Space | 재장전 / 점프 (길게 누르면 부스터 추력, 최대 상승 높이 제한) |
| M | 기체 선택 메뉴 |
| Esc / V | 일시정지 / 효과음 켜기·끄기 |
| F1 | 조작 가이드 열기·닫기 |

## 조작과 전투

- 모든 기체는 1번 슬롯의 같은 30발 고속탄 총을 사용합니다. 무기 전환은 잠시 보류하고, 기존 무기 콘셉트는 [기체 문서](docs/CHARACTERS.md)에 저장했습니다.
- 탄창이 비면 자동 재장전하며, R을 눌러 미리 재장전할 수도 있습니다. AI도 같은 총과 탄창을 사용합니다.
- Shift를 누른 채 이동하면 부스터 게이지를 소모하며 빨라집니다. Shift를 놓으면 부스터가 멈추고 게이지가 회복됩니다.
- Space를 누르면 적당한 높이로 점프합니다. 길게 누르면 부스터 에너지를 사용해 더 높이 오르지만 상승 높이에 제한이 있고, 하강은 더 빠르게 진행됩니다. 상승 중에는 발밑으로 부스터 불꽃이 보입니다.
- 점프와 장애물 이동은 현재 게임 코드의 직접 계산 방식이며 Unity Rigidbody 물리는 아직 연결하지 않았습니다. Rigidbody로 완전히 옮기려면 생성되는 지형·엄폐물에도 Collider를 붙이고 기존 이동/회귀검사를 함께 바꿔야 합니다.
- 마우스로 시야를 돌리고, WASD는 카메라 기준으로 움직입니다. 우클릭 락온 중에는 상대를 바라보고, 락온을 풀면 이동 방향으로 몸이 부드럽게 회전합니다.
- 격납고 MODE 버튼에서 AI VIEW를 고르면 양쪽 AI가 싸우고 쿼터뷰 카메라가 전장을 360도 선회합니다.
- 관전 중에는 가운데 휠 버튼을 누른 채 마우스를 움직여 카메라 방향과 각도를 조정할 수 있습니다.
- 추가 무기 선택과 AI 관전의 장시간 밸런스 집계는 후속 작업입니다.

## 전투, 부스터와 관전

기체 기본 이동 속도와 부스터 속도를 높였고, 이번 조정에서 8종 기체의 부스터 속도를 추가로 약 25% 올렸습니다. 보관 중인 프레임별 탄속도 조정했습니다. ACE의 회피 반응을 늦추고 회피 선택 강도를 낮춰 공격을 맞힐 틈을 늘렸습니다. AI 난이도는 PRACTICE / STANDARD / ACE이고 기본값은 PRACTICE입니다.

현재 모든 기체는 1번 슬롯에 같은 30발 고속탄 총 하나를 장비합니다. 무기 전환은 아직 제공하지 않으며 기존 8종의 개별 일반/특수 무기 콘셉트는 [기체 문서](docs/CHARACTERS.md)에 보관했습니다.

전투는 3인칭 추적 카메라를 쓰며, 마우스로 시야를 돌리고 WASD는 카메라 기준으로 움직입니다. 우클릭을 누르면 상대를 바라보며, 상대가 화면 밖이거나 장애물에 가려지면 락온이 풀립니다. 락온이 풀린 뒤에는 이동 방향으로 몸이 부드럽게 회전합니다. Space 점프는 상승 높이를 제한하고 하강 중 중력을 더해 빠르게 착지하도록 조정했습니다. 상승 중에는 로봇 발밑으로 부스터 불꽃이 나옵니다. 이동 중 Shift를 누르고 있으면 부스터가 작동합니다.

격납고 MODE에서 AI VIEW를 선택하면 AI끼리 대전합니다. 카메라는 쿼터뷰로 전장을 자동 선회하고, 가운데 휠 버튼을 누른 채 움직여 관전 각도를 조절할 수 있습니다.

지상 훈련장에는 중앙 진입로와 외곽 방향 약 24개의 컨테이너·발전 설비·방벽을 분산 배치했습니다. 낮은 지형은 걸어서 오를 수 있고, 낮은 엄폐물은 점프로 올라갈 수 있습니다. 기체 충돌은 둥근 발자국 반경으로 모서리 틈새를 계산합니다. 장애물은 기체와 탄환을 막으며 외곽 벽은 없습니다.
