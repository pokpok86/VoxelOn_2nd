# VoxSky 파츠 조합 설계

작성: 2026-10-27. 구현 완료 항목과 이후 설계안을 구분한다.

## 목표

플레이 대전은 3인칭 추적 시점에서 빠른 이동과 추격을 즐기고, 머리·몸통·팔·다리·무장을 조합한다.
밸런스 비교에는 회전 쿼터뷰 AI 대 AI 관전 모드를 활용한다. 조합을 AI 연습에서 시험한 뒤 온라인 1대1 대전으로 확장한다.
현재 8종은 고정 캐릭터의 최종 목록이 아니라 서로 다른 조립 예시/프리셋이다.

## 참고 조사

아머드 코어 VI 공식 초보자 가이드는 무기, 프레임, 내부 파츠가 서로 다른 역할을 맡고,
기동 관련 파츠의 선택도 무기 선택만큼 중요하다고 설명한다. 동시 이동과 공격의 중요성도 강조한다.
[공식 초보자 가이드](https://armoredcore6.bn-ent.net/en/information/?p=22)

공식 스타터 가이드는 머리, 코어, 팔, 다리 외에 부스터·FCS·발전기 등의 조합을 소개한다.
VoxSky에서는 처음부터 슬롯 수를 늘리기보다 사용자가 제안한 네 부위에 역할을 모은다.
[공식 스타터 가이드](https://en.bandainamcoent.eu/armored-core/news/armored-core-6-fires-of-rubicon-starter-guide)

개발자 인터뷰에서는 다리의 선택이 이동 방식 자체를 바꾸고, 무기는 발사 방식과 탄막으로 차별화한다고 설명한다.
VoxSky에서도 숫자만 다른 장비보다 순간 가속/순항/호버와 근접/직사/폭발의 조합을 우선한다.
[개발자 인터뷰](https://blog.playstation.com/?p=383443)

위 자료를 참고해 아래 규칙을 설계했다. 아래 수식과 수치는 아머드 코어의 실제 규칙을 복제한 것이 아니다.

## 현재 준비한 구조

`VoxArena.Robot.cs`는 로봇의 모든 형상을 각 모듈의 로컬 좌표로 생성한다.

```text
Fighter root
  Modular robot
    Head module
    Core module
      Backpack module
    Arms module
      Left arm socket
        Left weapon socket
      Right arm socket
        Right weapon socket
          Primary weapon module
    Legs module
      Left leg socket
      Right leg socket
```

몸체 형상과 무기 형상은 분리되어 있고, 팔을 기준으로 무기 소켓이 움직인다.
현재는 외형 구조만 모듈화했으며 수치는 `CraftSpec`에 있다. 파츠 교체 UI, 중량 계산과 저장 기능은 아직 없다.
팔·다리는 현재 좌우 한 쌍을 한 파츠로 다룬다. 개별 좌우 교체는 후속 설계에서 결정한다.

## 파츠별 역할 초안

| 부위 | 주요 능력 | 선택의 대가 |
| --- | --- | --- |
| 머리 | 조준 보조 각도, 예측 조준율, 무기 냉각 배율 | 강한 보조는 높은 중량 또는 느린 냉각과 교환 |
| 몸통 | HP, 장갑, 선택적 실드, 총 적재 한도 | 중장갑은 가속과 회피에 불리 |
| 팔 | 무장 장착 중량 한도, 반동 제어, 근접 효율 | 중화기 팔은 무겁고 경량 팔은 장착 선택 제한 |
| 다리 | 이동·부스터 속도, 연료, 소모, 순간/순항/호버 | 순간 폭발력과 지속력 사이 선택 |
| 무기 | 공격 유형, 피해, 탄속, 사거리, 재사용 시간, 중량 | 장거리·명중률·범위·피해를 동시에 극대화하지 않음 |
| 방패 무기 | 전방 방어, 내구/방어 게이지 | 무기 슬롯과 중량을 차지하고 측후면은 취약 |

자동 실드는 몸통의 선택 능력이고, 손에 드는 방패는 별도 무기다.
검 하나만 장착한 경량 조합도 유효하도록 최소 무장 1개만 요구하는 방향을 검토한다.
무기 슬롯은 처음에 좌/우 2개로 시작하고, 어깨 무기는 조작과 HUD가 안정된 뒤 추가한다.

## 중량 계산 제안 — 아직 미구현

- 총중량 = 머리 + 몸통 + 팔 + 다리 + 모든 장착 무기의 중량.
- 몸통 적재 한도와 팔 무장 한도를 각각 검사한다. 초과 시 출격 버튼에서 이유를 표시한다.
- 적재율 = 총중량 / 몸통 적재 한도.
- 이동 배율 = clamp(1.10 - 0.35 × 적재율, 0.75, 1.10).
- 부스터 소모 배율 = 0.85 + 0.40 × 적재율.
- 조준 보조 각도와 냉각 배율에는 상하한을 두어 무한 보정/무한 연사를 막는다.

위 값은 플레이 테스트용 제안이다. 현재 고정 프리셋에 몰래 중량 페널티를 적용하지 않는다.

## 조합 컨셉 8개

| 프리셋 | 머리·몸통·팔·다리 방향 | 무기와 운영 |
| --- | --- | --- |
| KESTREL | 균형 센서 / 중형 / 범용 / 호버 | 교차 사격으로 이동을 유도하고 스윕 레이저로 추격 |
| BASTION | 냉각 / 중장갑 / 중화기 / 순항 | 큰 플라스마와 정지 레이저, 사격 후 위치 변경 |
| WISP | 근접 추적 / 경량 실드 / 경량 / 순간 가속 | 근거리 연사와 검, 짧게 접근 후 이탈 |
| NOMAD | 유도 / 중형 / 미사일 / 고효율 순항 | 미사일 압박을 유지하며 거리를 관리 |
| SCATTER | 근거리 / 돌격형 / 산탄 / 순간 가속 | 산탄과 원형 탄막으로 접근전 |
| LANCER | 정밀 조준 / 경량 실드 / 반동 제어 / 호버 | 직선 저격과 짧은 충전 레이저 |
| TEMPEST | 추적 / 중형 / 에너지 / 추격 호버 | 파동탄과 정지 폭발 유도탄으로 퇴로 제한 |
| ANVIL | 범위 관측 / 중장갑 / 폭발 무기 / 순항 | 유탄과 지뢰로 지형 주변 통제 |

추가 무기 후보: 방패, 검 단독, 차지 샷건, 지속 화염/단거리 빔, 도탄 디스크,
시간차 클러스터, 직선 관통 레일, 전개형 비트. 각각의 카운터와 시각 신호를 정한 뒤 하나씩 도입한다.

## 단계별 구현 순서

1. 현재 전투의 명중률과 초보 난이도, 기체 구분을 안정화한다.
2. 파츠 데이터와 중량 계산기를 만들고 프리셋 8개를 조합 데이터로 변환한다.
3. 격납고에서 네 부위와 무기를 바꿔 보고 예상 성능을 비교한다. 저장/불러오기와 버전 정보를 추가한다.
4. AI 상대 프리셋 고정 선택, 정지 표적, 피해·명중률·평균 교전 시간 표시를 추가한다.
5. 온라인 실험 전에 입력과 전투 시뮬레이션을 렌더링/사운드에서 분리한다.
6. 권위 있는 호스트/서버가 장비 적합성과 피격을 검증하도록 한다. 지연 보정, 재접속, 양쪽 빌드 버전 일치를 검증한 뒤 대전을 확장한다.

현재는 로컬 AI 대전만 구현되어 있으며 온라인 기능은 없다.
