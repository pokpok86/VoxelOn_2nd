# 외부에서 VoxSky 개발 이어가기

확인: 2026-10-27. [OpenAI 공식 원격 연결 안내](https://learn.chatgpt.com/docs/remote-connections)를 기준으로 작성했다.
앱 버전과 기능 배포 상태에 따라 메뉴 이름이나 제공 여부가 다를 수 있다.

1. 집 PC와 휴대폰 앱을 최신 버전으로 유지하고 같은 ChatGPT 계정/워크스페이스로 로그인한다.
2. PC 앱의 Settings → Connections → Control this PC에서 Set up 또는 Add를 선택한다.
3. 표시된 QR 코드를 휴대폰으로 스캔하고 인증과 기기 연결을 마친다.
4. 휴대폰의 Codex 또는 Remote에서 집 PC와 이 대화를 열고 추가 지시나 결과 확인을 한다.
5. 다른 지원 PC에서는 Settings → Connections → Control other devices에서 연결할 수 있다.

집 PC는 전원, 네트워크, 앱 실행을 유지해야 한다. 절전이면 작업과 연결이 멈춘다.
연결 설정에 컴퓨터를 깨어 있게 유지하는 옵션이 있으면 사용할 수 있다.
Windows 화면 조작이 필요한 작업은 잠금 해제된 데스크톱이 필요하다.

원격 Codex는 개발 지시와 결과 확인 기능이다. 휴대폰에서 이 Windows 게임을 직접 실행하거나
실시간 게임 스트리밍을 제공하는 기능과는 다르다. 게임 실행은 프로젝트가 있는 집 PC에서 이뤄진다.
이 작업에서는 원격 연결이나 전원 설정을 변경하지 않았다. 기기 연결은 본인 인증을 거쳐 직접 완료하면 된다.
