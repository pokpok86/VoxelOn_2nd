# 기체 목록 — 6차 지상 로봇 프로토타입

> 현재 방향 변경(2026-10-30): 프레임마다 다른 과거 무장 패턴은 설계 자료로 보관한다. 플레이어와 AI는 공통 1번 주먹, 2번 30발 고속탄 총을 사용한다. 3·4번은 선택 슬롯만 표시하며 아직 무장이 연결되지 않았다. 아래 무장 표는 구현 중인 현재 로드아웃이 아니라 보관 중인 프레임별 콘셉트다.

각 기체는 일반 무기(왼쪽 버튼)와 특수 무기(오른쪽 버튼)를 사용한다.
수치는 첫 밸런스 초안이다. 실드는 WISP와 LANCER에만 체력의 15%로 적용하며, 방어력은 실드와 체력 피해 모두에 적용한다.

| 기체 | 일반 무기 / 기본 쿨타임 | 특수 무기 / 쿨타임 | 부스터 컨셉 |
| --- | --- | --- | --- |
| KESTREL | 양옆 2발 후 중앙 1발 / 1.35초 | 부채꼴로 훑는 레이저 / 9초 | 부드러운 호버, 중거리 교차 사격 |
| BASTION | 크고 느린 폭발 플라스마 / 1.85초 | 정지 충전 후 굵은 레이저 / 11초 | 느리고 오래 유지하는 중장갑 순항 |
| WISP | 짧은 사거리 6연발 고속탄 / 1.2초 | 상대에게 돌진하며 검 공격 / 8초 | 빠른 0.30초 순간 가속 |
| NOMAD | 유도 미사일 2발 / 1.75초 | 넓은 부채꼴 미사일 9발 / 11초 | 저소모 장거리 순항 |
| SCATTER | 근거리 산탄 7발 / 1.45초 | 원형 탄막 16발 / 9초 | 접근용 0.42초 순간 가속 |
| LANCER | 빠르고 가는 장거리 레일탄 / 1.8초 | 정지 충전 후 장거리 레이저 / 10초 | 조준 위치를 잡는 호버 |
| TEMPEST | 좌우로 흔들리는 3연속 탄 / 1.5초 | 추적 후 멈추고 폭발하는 유도탄 3발 / 10초 | 추격형 호버 |
| ANVIL | 범위 폭발 유탄 / 2.0초 | 주변 지뢰 5개 / 12초 | 지역을 장악하는 중장갑 순항 |

연발 쿨타임은 묶음 공격의 시작을 기준으로 한다. 유도 폭발탄과 지뢰는 폭발 예고 후 피해를 준다.
BASTION과 LANCER는 특수 무기 충전 및 발사 중 이동이 제한된다.

| 기체 | 체력 / 실드 | 방어력 | 기본 / 부스터 속도 | 부스터 용량 / 초당 소모 | 일반 탄속 / 반경 / 사거리 |
| --- | --- | --- | --- | --- | --- |
| KESTREL | 340 / 0 | 8% | 11 / 18 | 160 / 16 | 62 / 0.32 / 65 |
| BASTION | 460 / 0 | 28% | 8.5 / 14 | 190 / 12 | 38 / 0.85 / 58 |
| WISP | 290 / 43.5 | 2% | 13 / 30 | 120 / 72 | 90 / 0.20 / 30 |
| NOMAD | 350 / 0 | 10% | 10 / 16 | 230 / 9 | 44 / 0.34 / 70 |
| SCATTER | 370 / 0 | 12% | 11 / 24 | 155 / 48 | 58 / 0.38 / 32 |
| LANCER | 300 / 45 | 4% | 11.5 / 18 | 150 / 17 | 115 / 0.22 / 90 |
| TEMPEST | 330 / 0 | 7% | 11.5 / 20 | 155 / 19 | 58 / 0.32 / 62 |
| ANVIL | 430 / 0 | 22% | 9 / 14.5 | 200 / 11 | 42 / 0.65 / 52 |

속도와 거리는 게임 월드 단위다. 접근 부스터 최대 +18%, 후퇴 최대 -12%.
순간 가속은 Space를 놓았다 다시 눌러 재사용하고, 순항/호버는 유지한다.
호버는 가속과 감속에 관성이 있다. 메뉴 WEAPON TUNING 배율은 플레이어와 AI에 동일하게 적용한다.
기본 데이터는 `Assets/Scripts/CraftCatalog.cs`에 있다.

다음 단계는 실전 플레이로 명중률, 회피 여유, 무기 쿨타임과 교전 시간을 조정하는 것이다.
