## 2차 변경 (2026-10-26)

- 칼과 근접 피해 판정, 무기 전환을 제거하고 총만 사용한다.
- 플레이어와 AI가 항상 상대방을 바라보며 이동한다. 카메라는 고정 쿼터뷰를 유지한다.
- Shift와 고정 거리 대시를 제거한다.
- WASD 이동 중 Space를 누르면 초기 0.18초 2.2배, 유지 시 1.65배 속도로 이동한다.
  시작 에너지 8, 유지 소모 초당 24. Space를 놓으면 기본 이동으로 돌아온다.
- 방어 유지 초당 20, 정면 탄환 방어 시 원래 피해량 × 0.6만큼 에너지를 추가 소모한다.
- 방어 중 부스터와 사격은 불가능하다. 에너지 부족 시 방어가 해제되며 해당 탄환은 정상 피해를 준다.
- 소모 종료 후 0.8초 대기 후 초당 20 회복. 고갈된 기능은 버튼을 놓아야 재사용 가능하다.
- 아래 1차 구현 기록 중 칼/대시/Shift 관련 내용은 이전 버전의 기록이다.

## 구현 내용

- 고정 쿼터뷰 카메라와 블록 타일 경기장.
- 블록으로 구성한 임시 호버 기체 2대.
- 화면 기준 WASD 이동, 이동 방향에 따른 기체 회전.
- Shift 부스터, 회복 게이지, Space 대시와 경기장 경계 제한.
- 칼/총 선택, 정면 사격 각도 제한, 탄환과 피격 효과.
- 정면 방어, 간단한 거리 조절/공격 AI, 체력과 승패, 재시작/일시정지.

## 임시 결정

기체 형태는 확정되지 않았으므로 무장 호버 기체를 임시로 사용한다.
부스터와 대시는 같은 에너지를 사용한다. 대시 무적은 없고 방어 중에도 뒤에서는
정상 피해를 받는다. 키 3/4는 예약 상태다. 소리, 최종 모델, 정교한 애니메이션,
환경 장애물과 AI의 대시 회피는 아직 구현하지 않았다.

## 검증 방식

Unity에서 `VoxBuild.BuildWindows`를 실행해 씬 생성과 Windows 개발 빌드를 수행한다.
실행 파일에 `--smoke-test`를 전달하면 실제 게임 로직으로 직선/대각선 이동,
부스터 소모, 대시 거리, 사격 가능 각도, 각도 밖 발사 차단, 탄환 피해,
정면 방어, 칼 공격을 검사한 후 경기를 초기화하고 화면을 저장한다.
성공 시 플레이어 로그에 `VOXSKY_SMOKE_PASS`가 남고 종료 코드 0으로 종료한다.
이 검사는 키 입력 자체나 장시간 플레이 밸런스 검증을 대신하지 않는다.

빌드 로그: `Logs/Build.log`

실행 검사 로그: `Logs/SmokeTestVisible.log`

## 검증 결과 (2026-10-26)
