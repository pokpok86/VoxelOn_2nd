# Codex 클라우드 연결 준비

## 현재 상태

2026-10-27: GitHub 비공개 저장소 https://github.com/pok86/VoxSky 의 main 브랜치에 프로젝트 84개 파일을 업로드했다. `.gitignore`, `.gitattributes`, `AGENTS.md`를 포함한다. GitHub 로그인과 이 PC의 Git 업로드 인증, Codex 클라우드 연결을 완료했다. 개인용 환경 **VoxSky**를 게시했고 화면의 **게시됨 / 사용 가능 대상: 나만**을 확인했다.

클라우드 온보딩에서는 GitHub 읽기 접근, 패키지38개와 에셋 메타데이터24개 구조 검사가 통과했다. 게임 코드 변경은 없었다. 시작 지침에 프로젝트 맥락과 검증 한계를 저장했다. Unity Editor·라이선스·Windows 실행 환경은 제공되지 않아 컴파일 및 게임 실행 검사는 수행하지 않았다.

이제 ChatGPT/Codex에서 **작업 위치: 클라우드 → 환경 선택: VoxSky**를 선택하고 작업을 요청한다. 환경 게시 자체가 게임 개선 작업을 계속 실행하는 것은 아니다. 원하는 수정 작업은 별도로 요청한다.

## 연결 순서

1. GitHub에 로그인한다. 사용자 이름 대신 가입 이메일로도 로그인할 수 있다. 비밀번호와 인증 코드는 채팅에 보내지 않는다.
2. 비공개 VoxSky 저장소를 만들고 로컬 프로젝트를 올린다. Assets와 .meta, Packages, ProjectSettings, 문서를 포함하고 Library/Builds/Logs/Backups는 제외한다.
3. ChatGPT/Codex에서 Work in > Cloud의 환경 선택으로 들어가 환경을 만든다. GitHub 연결 후 VoxSky 저장소만 선택한다. 화면 이름은 앱 버전에 따라 다를 수 있다.
4. 환경 준비 결과와 가능한 검증 도구를 확인하고 게시한다. 처음에는 코드 검토와 소규모 수정을 맡긴다.
5. 결과를 검토하고 로컬에서 변경 사항을 받아 Unity 빌드와 실행 검사를 한 뒤 반영한다.

코드 작업은 집 PC가 꺼져 있어도 클라우드에서 진행할 수 있다. 단, 클라우드의 Unity 설치·라이선스·Windows 실행 환경은 아직 확인되지 않았다. 기본 계획은 클라우드에서 코드 수정, 로컬에서 게임 빌드와 플레이 검증이다.

## 첫 작업으로 사용할 요청

> AGENTS.md와 README.md를 읽고 VoxSky 구조를 파악해 줘. 우선 게임 코드는 변경하지 말고 AI, 무기, UI, 로봇 모듈의 파일 관계를 한국어로 설명해 줘. 이 클라우드 환경에서 Unity 6000.6.7f1 컴파일과 실제 실행 검사가 가능한지 확인하고, 가능하지 않으면 로컬에서 필요한 검증을 분명히 적어 줘. 게임 밸런스·그래픽·패키지 버전은 바꾸지 마.

## PC를 바꿔 작업할 때

작업 전에 최신 변경 사항을 받고, 작업이 끝나면 저장소에 올린다. 두 PC와 클라우드에서 같은 파일을 동시에 수정하지 않는 방식으로 시작한다. Codex 로그인만으로 로컬 프로젝트 파일이 자동 복사되지는 않는다.
