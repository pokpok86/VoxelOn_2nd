# VoxelOn — SOL 개발 요청서 (2026-11-04)

> 담당: 박PD(방향/승인), 맥스(요구사항/검토), 솔(SOL GPT 모델, 구현)
> 상태: **기획/개발 요청 — 미구현, 미검증**. 이 문서의 커밋은 기능 구현을 의미하지 않음.
> 원칙: 관련 작업은 묶어서 구현하고, 실제 Unity 빌드·스모크·플레이 테스트 결과를 보고한다. 기존 조작/파츠/카메라 기능을 깨뜨리지 않는다.

## 개발 순서 제안

1. **플레이 가능한 기체 확대**: DEV-002 → DEV-001 (외형 때문에 기획·밸런스가 멈추지 않도록 프로토타입 우선)
2. **전투 핵심 루프**: WEAPON-001 + AIM-001 + AI-001 + BAL-001 + MOVE-001
3. **전장과 정보전**: MAP-001 + MAP-002 + RADAR-001
4. **시각적 완성도**: ENV-001 + VFX-001 + VFX-002
5. **카메라**: CAM-001은 맥스 검토 담당. 솔은 변경 전 협의하고 회귀 테스트할 것.

## DEV-002 — 2·3번 기체 Blender 프로토타입 [높음/신규]

- **목적**: 새 기체 그래픽 제작 지연이 게임플레이 기획·밸런스 검증을 막지 않도록, 기존 WISP 상체를 최대한 재사용한다.
- **디자인 참고**: 박PD가 지목한 **건담 데스크탑 V**의 SD 비율과, 건담 V작전 3기(건담/건캐논/건탱크)의 명확한 실루엣·역할 차별화. 드라고나 D1/D2/D3의 범용/화력/전자전 콘셉트도 참고 가능. **원작 기체의 형태·문양을 그대로 복제하지 않고 VoxelOn 고유 디자인으로 재해석**.
- **1번 WISP**: 기존 이족보행 기본 기체 유지.
- **2번 BASTION**: WISP 상체·머리·팔·무장 마운트를 재사용하고, 하체를 **무한궤도/탱크형**으로 교체. 낮고 묵직한 실루엣. 전진 중심 고속 기동, 측면 고속 기동 제한.
- **3번 TARANTULA**: WISP 상체·무장 마운트를 재사용하고, 하체를 **다족(거미형, 초기 사족)**으로 교체. 고속 대시 제한, 안정적 지형 이동. 건캐논식 중장갑 인상이나 드라고나 D3식 센서 특징은 참고만.
- Blender 원본과 Unity용 FBX/프리팹, 하체 애니메이션/충돌체/지면 접촉을 구성한다. 기존 무기 4슬롯 호환성 유지.
- **1차 목표는 완성된 외형이 아니라 플레이 가능한 서로 다른 이동 타입 3기**. 이후 상체/머리/어깨 디테일을 차별화.
- 검증: 3기 선택·스폰·이동·점프/부스터·사격·피격·카메라·충돌·빌드 확인.

## DEV-001 — WISP 어깨 관절 보강

- 어깨 장갑과 팔 사이 빈 공간에 어두운 기계식 관절 하우징, 회전축, 내부 프레임 추가.
- 정면/측면/후면에서 부자연스러운 틈이 보이지 않으며 팔 움직임·무장 장착을 방해하지 않을 것.

## WEAPON-001 — 사격, 탄창 관리, 재장전, 탄약 HUD [높음]

- 기존 **리로드 버튼** 그대로 사용. 잔탄이 남을 때 수동 재장전 가능, 탄창 소진 시 자동 재장전.
- 빈 탄창은 수동 재장전보다 **명확히 오래 걸리게**: 테스트 초안 잔탄 재장전 **2.5초**, 빈 탄창 **4.0초**. 무기별로 차등 조정 가능.
- 재장전 중 해당 무기 발사 불가, 이동/점프/대시는 허용. 네 무기 슬롯의 탄약/재장전 상태를 독립 관리.
- 전투를 더 묵직하게: 초기 시험값 **탄환 피해 +15%, 발사 빈도 -35%, 탄환 시각 크기 +15%**, 탄속은 우선 유지. 무기 종류별 연사 차이 유지. 탄환 크기 확대에 따른 히트 판정 증가는 별도 검증.
- 손 무기 잔탄/재장전 상태는 조준점 가까이에 간결하게, 어깨 무기는 HUD 하단에 표시. 탄 부족/빈 탄창/장전 완료 피드백.
- 적도 긴 장전 틈을 이용해 반격할 수 있도록 AI에 같은 규칙 적용.
- **수치는 확정 밸런스가 아닌 테스트 초안**. 실제 전투 시간, DPS, 명중률 검증 후 조정.

## AIM-001 — 약한 보조 락온 및 조준점 수렴 애니메이션 [높음]

- 완전 자동 락온/유도탄이 아님. 적이 조준점 가까이 있고 **시야 사이에 장애물이 없을 때만**, 발사 순간 탄도 방향을 소폭 보정. 카메라/조준점을 강제로 끌지 않는다.
- 적이 멀리 벗어나거나 엄폐 뒤로 숨으면 보정 중단. 발사 후 탄환은 정상 탄도.
- **정지 > 일반 이동 > 점프·공중 이동 > 고속 대시** 순서로 보조 조준 성능 약화. 시험 상대값 100/65/50/25%; 정지 후 0.3~0.5초 안정화. 숫자와 강도는 테스트로 조정.
- 보조 락온 진입 시 조준점 주변 반투명 잔상 3~4개가 **0.2~0.4초 동안 중심으로 수렴**, 활성화 시 짧은 청록색 피드백. 해제 시 자연스럽게 흩어짐. 깜빡임/반복 초기화 방지.
- **조준 안정도 게이지는 넣지 않는다.** 조준점은 작고 깔끔하게 유지.
- 실제 보정 활성 시점과 시각 피드백 일치. 근거리·장거리·엄폐·이동 상태 회귀 테스트.

## AI-001 — 전투 AI 기동과 반격 가능성 [높음]

- 단순 접근→사거리 내 무한 공격 패턴 개선: 회피, 재배치, 후퇴, 사격 간격, 반응 지연/조준 오차를 혼합.
- 현재 거의 사용하지 않는 **점프·공중 조향·부스터·대시**를 공격받거나 지형을 넘을 때 상황에 맞게 활용.
- 기체별 이동 타입/무기/재장전 규칙을 준수. AI가 항상 완벽하게 대응하지 않도록 읽을 수 있는 빈틈을 만든다.
- AI가 높은 지형·장애물을 따라 이동할 수 있는지 검증. 무작위 점프 반복은 피함.

## BAL-001 — 실력 기반 역전 기회 [높음]

- 핵심 목표: **불리한 상황에서도 조작·탄약 관리·지형 활용·상대 빈틈 포착으로 역전 가능**. HP가 낮다는 이유만으로 자동 화력 보너스는 주지 않는다.
- 후보: 실드 소진 후 짧은 회복 지연, 강한 무기 연속 사용 후 과열/공격 빈틈, 고저차/엄폐 파괴, 부위별 일시적 기능 저하, 조작 기반 긴급 회피.
- **모든 후보를 한 번에 구현하지 말 것**. 우선 재장전 빈틈+AI 실수+지형 활용을 검증하고, 필요 시 실드 파괴 빈틈을 추가.
- 테스트 모드에서 서로 다른 HP/탄약 상황으로 반복 전투하여 역전 가능성과 불공정함을 점검.

## MOVE-001 — 이동속도와 방패 페널티

- 기본 이동속도 소폭 하향(이전 제안 -10%는 **미확정 초안**). 방향별 이동비, 기체 타입 차별화 유지. 대시 속도와 점프 높이는 우선 별도 변경하지 않음.
- 방패 장착/방어 중 이동속도를 소폭 낮추되, **향후 방패 종류별로 페널티를 다르게 설정 가능한 데이터 구조**를 준비. 특정 -5%/-10%는 확정하지 않음.
- 방패별 방어 범위/내구도/에너지/특수 효과는 추후 기획. 기동성이 답답해지지 않게 검증.

## MAP-001 — 기존 실외맵 자연 지형, 물, 시간대, 날씨

- 실내 계단처럼 보이는 규칙적인 장애물을 자연 암석, 침식된 지형, 바위 더미 등으로 교체. 기존 엄폐·이동·점프 경로는 가능한 유지.
- 낮은 곳에 **얕고 바닥이 비치는 투명 물웅덩이** 배치. 진입·걷기·대시·착수 시 첨벙 물보라/파문. 얕은 물의 이동 페널티는 우선 없음.
- 푸른 하늘/구름 Skybox, 원거리 산·절벽, 태양광·부드러운 그림자, 금속·수면 반사. 적과 조준점 시인성 유지.
- 라운드 시작 시 **밝은 아침/어두운 저녁** 시간대와 **맑음/흐림/비/뇌우** 날씨 프리셋 랜덤 선택, 라운드 중 고정. 테스트 모드에서 강제 선택 가능.
- 비: 젖은 지면·물웅덩이 잔물결. 뇌우: 드문 먼 번개와 짧은 조명 변화, 과도한 섬광 방지.
- 파티클/셰이더·LOD·풀링으로 성능 관리.

## MAP-002 — 벽이 보이지 않는 초광역 평야

- 눈에 띄는 인공 경계벽 없이 광활하게 보이는 평야, 먼 지형과 수평선.
- **큰 고저차**: 높은 언덕, 깊은 골짜기, 절벽, 점프/부스터가 유리한 지름길과 일반 이동 우회로. 높은 지형이 무조건 우세하지 않게 접근로·엄폐 균형.
- 실제 무한 맵은 필수 아님. 플레이 가능한 영역은 안전하게 관리하되 경계가 자연스럽게 느껴지도록 구성.
- 먼 적 탐색, AI 경로 탐색, 낙하 후 복귀 불가 지형, 원거리 렌더링/LOD 검증.
- MAP-001의 시간대·날씨 시스템 재사용.

## RADAR-001 — 머리 파츠별 탐지 범위와 기상 영향

- 레이더 **탐지 거리**를 머리 파츠 속성으로 추가.
- 탐지 범위 안: 적의 상대 위치를 레이더에 점으로 표시.
- 탐지 범위 밖: 정확한 거리/좌표 대신 **레이더 내부 가장자리의 방향 화살표** 표시. 범위 밖 화살표의 정보 획득 조건(항상 표시 vs 과거 탐지 이후 표시)은 **박PD 미확정**, 임의로 고정하지 말 것.
- 날씨에 따라 레이더 성능 변화: 시험 초안 맑음 100%, 흐림 95%, 비 85%, 뇌우 65~80% 및 간헐적 노이즈. 최소한의 방향 정보와 조작 가능성 보장.
- 머리 파츠 교체/날씨 전환/적의 고저차/원거리 상황에서 레이더 검증.

## ENV-001 — 파괴 가능한 자연 장애물과 복셀 잔해

- 대부분 장애물에 내구도 부여, 큰 바위는 높은 HP. 파괴되면 엄폐/충돌체도 실제로 사라짐. 바닥·경계는 유지.
- 타격→균열→폭발→**큰 조각 몇 개+작은 복셀 다수**가 여러 방향으로 튀고 회전·낙하·소멸. 원재질 색감, 먼지/충격파 표현.
- 비주얼 파편은 물리·충돌 비용을 제한하고 풀링 적용. VFX-002와 공통 파괴 시스템 재사용 검토.

## VFX-001 — 부스터 시각 효과

- 노즐 에너지 코어/광원, 점프·공중 재상승·대시별 분사 길이/방향/잔상 차별화.
- 출력과 이동 방향에 반응, 부드러운 소멸. 조준점 가림과 과한 화면 이펙트 방지.

## VFX-002 — 피격 부위별 손상과 기체 파괴

- 팔·어깨·다리·몸통 등 피격 부위에 짧은 스파크, 누적 손상에 약한 연기, 중손상에 간헐적 스파크. 수리/리스폰 시 정리.
- 격파 시 머리·팔·무장 등 큰 파츠 분리 + 몸통 장갑의 다양한 크기 복셀 파편 + 연기/불꽃. FBX 메시가 실제 복셀이라고 가정하지 말고 분리 파츠/시각적 근사 활용.
- ENV-001의 파편 시스템과 재사용 가능하게 설계.

## CAM-001 — 카메라/조준 시야 [맥스 담당, 솔 변경 시 협의]

- 현재 카메라는 기체가 조준점을 가리지 않도록 높이·거리를 조정했고 헤드 페이드/엄폐 카메라 처리도 존재. 이를 깨지 말 것.
- 가능하면 WISP를 화면에 더 크게 보이게 하되 조준점 가림 금지.
- 점프·대시·착지·벽 근처 카메라 흔들림/클리핑, 마우스 조준과 실제 탄도 일치 검증.
- **현재 변경 지시가 아니라 검토 항목**.

## 공통 완료 기준 및 보고 양식

1. 각 작업별 구현 여부와 변경 파일을 명시한다. 미구현 항목은 완료 처리하지 않는다.
2. Unity 실제 빌드 및 관련 스모크/플레이 테스트를 수행하고 결과를 기록한다. 테스트할 수 없다면 이유와 미검증 범위를 밝힌다.
3. 기능 추가 / 기능 변경 / 버그 수정으로 나눠 요약한다.
4. 1차로 DEV-002의 세 기체가 플레이 가능한지 검증하고, 이후 전투·맵·VFX를 단계적으로 진행한다.
5. 박PD가 최종 승인할 수 있도록 주요 밸런스 수치와 화면 비교 자료를 남긴다.
6. 본 요청서는 **개발 지시서**이며, 승인 없이 모든 항목을 일괄 완성했다고 간주하거나 대규모 자동 실행을 시작하지 않는다.
