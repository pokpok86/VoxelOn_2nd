# 실제 렌더링 프레임 점검

2026-10-27 03:55 KST 작업. `--performance-test`로 세 교전을 각각 9초 실행했다.
각 구간 첫 1초를 제외하고 실제 프레임 사이의 경과 시간을 측정했다. 가속 시뮬레이션 처리 속도가 아니다.
체력은 부하 유지를 위해 회복시키고, 오디오는 끄며 사용자 설정은 저장하지 않는다.

환경: RTX 3070, Ryzen 5 7500F, Windows 개발 빌드, 1280×720.
VSync=1이므로 화면 주사율 144Hz에 맞춰 측정되었다. targetFrameRate=120보다 VSync가 우선한 결과다.

로그 `Logs/Performance0355.log`, 종료 코드0. 측정 캡처 `Builds/PerformancePreview.png` 확인.
이 PC와 짧은 세 교전에서는 큰 프레임 지연이 없었다. 다른 GPU/해상도, 장시간 플레이, 오디오 포함 성능은 보장하지 않는다.
측정이 주사율에 제한되므로 최대 GPU 성능을 나타내지도 않는다.
문제가 관측되지 않아 이번에는 위험한 렌더링 구조 변경이나 불필요한 최적화를 하지 않았다.
